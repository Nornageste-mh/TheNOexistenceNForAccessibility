0.0.0.5: 白名单界面里的纯文本也纳入导航（回想朗读 / 重读上一句）

玩家提议：与其另造一个「重读上一句」的机制，不如把 History（回想）面板
纳入导航 —— 游戏本来就有这个面板，读出来玩家就能自己控制节奏，
翻到哪读到哪，回车重念当前这条。更优雅，也更省事。

为此把 UiNav 的导航项从「只能是 Selectable」泛化为 Component：
既可能是控件，也可能是纯文本。改动是机械性的，涉及：
- Group.Items / Items 属性 / ItemKey.S / CurrentItem / _announcedItem /
  _rescanRequestedFor / _pendingQuit 的类型
- GroupOf / VisiblyClickable / SameList / Describe / TextOf /
  RowLeftOf / OwnTextOf / RowTextOf / AliasOnSelf / AliasAncestorOf /
  AncestorNameOf / Activate / NeedsQuitConfirm / QuitConfirmArmed / ArmQuitConfirm
- Activate 对纯文本项的处理：没有可点的东西，回车 = 再念一遍

新增配置 [界面导航] 可导航文字的界面（默认 BacklogUI）：
命中这些路径的界面里，TMP_Text 也会变成导航项。
两个过滤条件：
- 跳过按钮/开关自带的标签（那些由控件本身代表，重复念是噪声）
- 跳过被 CanvasGroup 藏起来的

⚠️ 这是对 UiNav 的一次较大改动，导航行为需要重新实机验证：
主菜单 Tab、游戏内 Tab（History / Options）、选项框数字键都要回归一遍。
