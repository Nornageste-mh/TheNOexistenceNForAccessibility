## 0.2.1.0 正式版更新了什么（2026-11-22）

**正式版与 Preview EXP2 功能相同，只是版本号和发布标签转正。** 2026-11-22 玩家实测通过后发布；
日志头为 `=== NoExistence A11y v0.2.1.0 ... ===`（不再带 `Preview`）。

- **选项确认修复**：选项面板出现时临时关闭 uGUI 键盘提交，面板关闭后还原；数字键、方向键 + 回车选中的都与播报一致。
- **QTE 手动键盘**：自动通过关闭（默认）时用 `↑` `↓`（`Home` / `End` 首末）选按钮、回车 / 空格按下，每颗按钮一声「按」节拍提示；`F3` 仍随时可自动通过。
- **`Alt+M` 任何页面响应**：先交还当前页面，再尝试显示 / 创建对话 HUD（1.5 秒内每 0.2 秒重扫），失败念「没能打开对话界面按钮。」；日志前缀 `[UiNav] HUD：`。
- **此前各版的改动一并包含**：页面合并 / 遮挡保留 / 双扫接管 / 被排除模态防点穿 / 选项让行、性能降噪（`详细日志` 默认 `false`）、配音行完全静默与重读缓冲收窄、滑条修复。
- **测试模式（开发者后门）默认关闭**，正式游玩不要打开；配置共 43 项。

## 0.2.1.0 Preview EXP2 更新了什么（预览版，已由正式版取代）

**这一版不改变已有键位，补的是「选项确认对不对」「QTE 能不能手动打」「`Alt+M` 在某些页面不响应」。**

- **选项确认修复（重要）**：以前选项出现时，游戏自己会选中某个选项按钮，你按回车可能先被
  游戏自己的提交通路吃掉，出现「念的是 A、确认的是 B」。现在选项面板出现时，补丁会
  **临时关掉 uGUI 的键盘提交**，面板关掉后原样还原；数字键、方向键 + 回车都走同一条
  「先念标签、再点」的路径，选中的一定是你听到的那一项。
- **QTE 可以手动通关**：自动通过关着时（默认），反应环节里用 `↑` `↓`（`Home` / `End` 首末）
  在按钮间选择，每移动一次念「第 i 个，共 N 个」；按回车 / 空格 / 小键盘回车按下当前按钮；
  每颗按钮出现后有一声「按」的节拍提示。**手动是按「当下出现的按钮」点，听着提示抓时机**；
  还没按钮时按回车会念「还没有出现按钮。」。`F3` 仍可随时开关自动通过。
- **`Alt+M` 任何页面都响应**：以前只在剧情期 / HUD 页响应，现在在菜单里按也会先交还当前页面，
  再尝试显示 / 创建对话 HUD（最多 1.5 秒、每 0.2 秒重扫）。成功念「正在打开对话界面按钮。」，
  失败念「没能打开对话界面按钮。」；失败不影响剧情和其他菜单，排查请搜日志里的
  `[UiNav] HUD：`（不受「详细日志」开关影响）。
- **设置界面「你 / 我」按钮**：仍由游戏按结局状态决定启用 / 禁用，禁用时鼠标也点不动，
  扫描不到属正常，**补丁不处理**。
- **测试清单**：文末 T1–T12 已更新，重点看 T4（选项一致）、T6（QTE 手动）、T8 / T9（`Alt+M` 与 HUD）、
  T10（「你」按钮）。

> EXP2 这批改动已在正式版发布前由玩家实测通过（2026-11-22）；本小节保留作历史，复测项见文末 T1–T12。

## 0.2.1.0 Preview EXP1 更新了什么（预览版，已由正式版取代）

**这一版不改变已有键位，补的是「剧情期怎么用键盘」和「选项的键盘确认」。**

- **剧情期 `Alt+M`（实验性）**：游戏在纯键盘剧情期从不创建对话界面按钮（HUD），
  补丁现在会尝试让引擎创建并显示它（最多等 1.5 秒、每 0.2 秒重扫）。成功会念

- **HUD 页可以正常操作**：`↑` `↓` 选、回车激活；从 HUD 进入历史 / 设置会直接切到对应
  面板继续操作；如果是补丁创建的 HUD，退出 HUD 页时补丁会把它隐藏。
- **选项可以用键盘确认**：`↑` `↓` / `Home` / `End` 浏览，回车或空格确认；数字键 `1`–`9`

- **设置界面「你 / 我」按钮**：反汇编确认是游戏按结局状态决定启用 / 禁用的

- **文档措辞修正**：上一版把「剧情期键盘」说得太绝对 —— 菜单 / 面板类界面仍然自动接管；

## 0.2.1.0 更新了什么

**这一版不改变键位，改的是「一页里能看到哪些控件、什么时候接管、以及性能」。**

- **页面合并**：一个界面里的所有控件现在合成一页——标题画面那个「不」字滑条
  终于和 5 个按钮在同一页里可达；CG 画廊的返回按钮和格子、翻页也在同一页。
  页内统一按屏幕位置排（先上后下、同一行先左后右）。
- **遮挡不再误伤**：以前「看得见但被装饰 / 穿透层挡住」的按钮会被排除，
  画廊和 Tips 的返回按钮就因此被藏起来、玩家被困死。现在只排除画面外的和
  `CanvasGroup` 隐藏的，其余保留可激活（游戏按钮本来就不看射线）。
- **接管更稳**：同一界面连续两次扫描（约半秒）才接管，避免设置面板淡入时
  只扫到半个界面；接管后 0.8 秒内界面变化不重复播报；列表刷新时按原来的项
  保持焦点，不再漂移。
- **不会点穿被挡住的界面**：最上层是存档 / 读档、开发者面板这类被排除界面时，
  补丁暂不接管，回车不会点到背景的标题画面。
- **选项框出现时完全不接管**：键盘交给数字键 `1`–`9` / `0`。
- **性能**：`详细日志` 默认关闭（旧版默认开；实测一次会话 10MB 日志里 84.7%
  是界面扫描清单，是卡顿主因）；打开时也最多每 10 秒写一份；
  空闲扫描会自适应放慢；去掉了逐控件的 UI 射线检查。
- **配音行完全静默**：有配音的剧情行不念正文、不报角色名、不进重读缓冲
  （退格也读不到）；重读缓冲只保存**未配音**的剧情正文和选项。

两处美术字控件已用反编译/资源取证（Il2CppDumper + 预制体解析）核对过，结论如下，仍建议按 T4/T5 真机复测：

- **标题画面的隐藏成就滑条**（`TitleUI/LogoPanel/Image_Title/Slider`，SnappableSlider，0～1.5）：
  唯一监听是 `DissolveController` → `Material.SetFloat("_DissolveValue")`，只改变标题插画
  的溶解/显隐外观，**不切换标题、不参与 Konami 成就判定、不影响音效**。本版标签改为
  「标题插画显隐」，左右键能调，念「xx%（当前 / 1.5）」。
- **设置界面「你的设置」里的「你」字按钮**：它是 `SettingsUI/PlayerView/TitlePanel/TextPlayer`
  上的普通 `UnityEngine.UI.Button`（`CharacterView` 对应的是「我」/`TextCharacter`），
  prefab 里本来就是 active、可点。游戏在 `GameSettingsMenu.SetUIState` 里**按结局进度**
  决定启用/禁用（某些结局状态下按钮是关的，鼠标也点不动，不是补丁漏扫）；只要游戏把它
  启用，本版就能导航到，标签为「设置视图切换」。
- **Konami 成就「视觉小说高手」**：RE 确认 `TitleMenu` 用 legacy `Input.GetKeyDown` 逐键读
  「上上下下左右左右BA」、每键 1 秒窗口，不经过 EventSystem/Naninovel；本补丁只读按键、
  不合成输入、接管期间 `AddBlockingUI` 只挡「Continue/Submit」，因此**推断不影响该成就**，
  但仍请按 T5 实机确认。

## 这个补丁做了什么

**读台词。** 对话、旁白、章节标题、ED 字幕全部朗读。**有配音的剧情行完全静默**——不念正文、不报角色名、也不进重读缓冲（声音交给游戏语音）；没配音的用 TTS 念，并且**先报说话人名**。

**读选项。** 本作主角**从不用文本说话**——她/他的全部台词都在选项框里，全剧 625 条以上、8000 多字。补丁会在每条选项出现时带序号念出来；按 `1`–`9` 直接选，也可以**用 `↑` `↓` 浏览、回车（或空格）确认**。

**能不用鼠标玩。** 标题、设置、回想、笔记本、确认框等菜单**一出现键盘直接可用**，
不需要先按任何键进入什么"模式"；剧情对话里那两个只有鼠标入口的按钮（设置/回想），
用 `Alt+M` 单独进出（**实验性辅助链路**：游戏没创建 HUD 时补丁会尝试让引擎创建；
**任何页面按 `Alt+M` 都响应**——先交还当前页面再尝试，最多等 1.5 秒。
成功会念「正在打开对话界面按钮。」，失败念「没能打开对话界面按钮。」；2026-11-22 用户实测通过）。

**QTE 可以听、也可以选。** 剧情里有一处纯视觉的限时反应小游戏，默认**不替你操作**：
只播报"按 F3 可以自动通过"，要不要用由你决定。详见下面「反应环节（QTE）」。

**滑条可调、可听。** 音量、文字显示速度等滑条用左右方向键调整，每次 5%，
会念出「标签，滑条，当前值，每次 5%」；按住不放会连续调整。

## 怎么操作

### 朗读相关

| 按键 | 作用 |
|---|---|
| `1`–`9` | **选项出现时直接选第 1–9 项**，不必用鼠标、也不必先按任何键；也可以改用 `↑` `↓` 浏览、回车（或空格）确认 |
| `0` | **沉默键**：立刻让朗读闭嘴。默认 `0`——剧情里用不到数字键，不会和选项冲突 |
| **`退格`** | **重读**。界面操作接管时重读**当前这一项**；没接管界面时重读**最近一次未配音的剧情正文**（或整组选项）。只重读最近一次，不往回翻；**有配音的台词完全静默、不进重读，退格也读不到**；QTE / 加载 / 界面播报不占用重读。记忆只在内存里，退出游戏即清空。想翻更早的内容，去回想（History）界面逐条走 |
| **`F9`** | **切换语音后端** —— 按一下切到下一个**当前可用**的后端（循环顺序 `自动 → Tolk → NVDA → 争渡 → SAPI`），当前不可用的会被跳过并在播报里说明；选择会写进配置文件，下次启动仍生效。留空配置项即停用 |

> **`F9` 和中文 Windows 的输入法**：`Alt+Shift` 是 Windows 默认的**输入法 / 输入语言切换键**，
> 所以「和游戏抢键」时最顺手的 `Alt+Shift+F9` 用起来也可能别扭。
> 「切换语音后端按键」接受任何「修饰键+主键」写法（`F9`、`Alt+Shift+F9`、`Ctrl+Alt+F9`…），
> 但**修饰键必须完全对上** —— 配置写 `F9` 时，按住 Alt 再按 F9 **不会**触发
> （这是刻意的：免得抢走游戏自己的键）。纯数字键名会被拒绝，要数字键请写 `Alpha0`。

### 界面（菜单、设置、回想、确认框……）

> **没有"导航模式"。** 菜单一出现，键盘就是可用的——直接按方向键。
> 菜单关掉后，键盘自动交还给游戏。不需要按 `Tab`，也不需要记任何"进入/退出"键。
>
> **一页 = 游戏自己的一个界面。** 同一界面里的所有控件（包括被装饰挡住的、
> 不在同一个 Canvas 组里的）都会合到一页里：所以标题画面那个「不」字滑条
> 和 5 个按钮同页可达，画廊的返回按钮和格子 / 翻页也在同一页。
> 面板淡入需要一点时间，补丁要**连续两次**看到同一页才接管，**大约半秒**；
> 接管后 0.8 秒内界面变化不重复播报。最上层是存档 / 开发者面板这类被排除界面时，
> 补丁故意不接管，免得回车点到背后的画面。

| 按键 | 作用 |
|---|---|
| `↑` `↓` | 上一项 / 下一项（循环，会念出是什么、当前值、第几项） |
| `Home` / `End` | 第一项 / 最后一项 |
| `回车` / `空格` | 激活当前项：按钮、开关、滑条、输入框、退出确认 |
| `←` `→` | **只对滑条生效**：每次 5%，念出新值；**按住约 0.45 秒后连续调整**（每 0.12 秒一次），到顶会念「已到顶」。不是滑条的项上按左右键不会有反应，也不会吞掉游戏自己的键 |
| **`退格`** | 重读当前这一项 |
| **`Alt+M`** | **进入 / 退出「对话界面按钮」**（实验性）。剧情对话时屏幕上的「设置」「回想」按钮，游戏只留了鼠标入口；按这个键后：HUD 已存在就直接进入；不存在时补丁会尝试让引擎创建它（最多等 1.5 秒），期间念「正在打开对话界面按钮。」，成功列出当前可用按钮，失败念「没能打开对话界面按钮。」。进入后方向键选、回车激活；从里面进历史/设置会自动切到那个面板。**EXP2 起任何页面都能按**：如果当前正在别的菜单里，会先交还那个页面，再尝试打开 HUD；其他菜单平时仍自动接管，不需要按它 |
| `Esc` | **补丁不接管，交还游戏**：游戏自己的 `Esc`（返回 / 关闭菜单）照常生效；菜单关掉后补丁自动退出界面操作，不额外播报 |

**界面播报是什么样**：进入菜单先念「设置界面，共 5 项。」，然后念当前项
「文本显示速度，滑条，55%，共 100%，每次 5%。2 / 5」——
界面名、共几项、当前项是什么、当前值、第几项都能听到。

**页面名**是按游戏自己的界面认的：标题画面、设置界面、回想、笔记本、确认、
存档读档、暂停界面、画廊、提示、对话界面按钮、手机；认不出的会念「当前界面」。

**整屏控件都不可用**（例如彩蛋的「莉莉丝的设置界面」）：进入时会先提示
「这一屏的控件当前都不可用，只能听，不能选。」，所有项都能听、标签后面带「不可用」，
按回车只会听到「该项当前不可用。」——**绝不会替你点下去**。

**退出游戏有二次确认**：标题画面角落那个「退出游戏」只按一下就会关掉整个会话，
而读屏分不清它和旁边的「开始」，所以补丁补一道确认：
第一次按回车/空格念「这是退出游戏。再按一次回车或空格确认退出，按别的键取消。」，
再按一次才真的退。

**输入框（如果有）**：回车进入输入框后直接打字，打字时补丁**一个键都不抢**
（包括退格——那是删字，不会被拿去重读）。按游戏自己的方式离开输入框后继续。

**选项框**：选项出现时自动整组朗读，**用 `↑` `↓` 浏览、`Home` / `End` 跳到首/末、回车或空格确认**；
`1`–`9` 数字键仍可直接选。选项框属于"不是菜单"的界面，界面操作不会自动接管方向键
（方向键交给选项自己处理）；此时补丁会替游戏挡住「推进剧情」，按回车不会顺手把剧情过了。
**EXP2 起，选项面板出现时补丁还会临时关闭 uGUI 的键盘提交**（面板关掉后原样还原），
数字键和方向键都走同一条「先复述标签、再点」的路径——所以**选中的一定是你听到的那一项**，
不会再出现「念的是 A、确认的是 B」。

**游戏原生占用的键（补丁不会去抢）**：`回车` / `空格` 推进剧情、按住 `Ctrl` 快进、
`Esc` 返回、鼠标左键推进。`退格`、`0`、`F9`、`Alt+M` 都能在配置里改或关掉。

**和 Framework《操作逻辑公约》不一样的地方（摘要）**：

- 切换语音后端用 `F9`，不是公约默认的 `Alt+Shift+F9`——`Alt+Shift` 是中文 Windows
  的输入法切换键，避开对玩家更省事；
- `Alt+M` 是本作**新增**的「对话界面按钮」入口（公约语义表里没有这个动作）：
  剧情对话时屏幕上的设置/回想按钮游戏只留了鼠标入口；
- `Esc` **不接管**，直接交还游戏（本作 `Esc` 是游戏原生返回键）；
- `Home` / `End` 是补充键（公约默认没有，用来快速跳到第一项/最后一项）。

完整登记（每个键的语义、与公约的对应关系、证据、复测项与细节风险）见
[操作约定.md](操作约定.md)。

### 反应环节（QTE）

剧情第一章末尾有一处限时反应小游戏（烤箱那段）：按钮散落在屏幕上、
**透明 → 最实 → 渐隐消失**，得分取决于**点击瞬间按钮的凝实程度**，低于阈值要重来。
画面上没有任何可听的线索，盲人玩家不是玩得差，是根本没有可玩的通道。

**默认不替你操作。** 进入反应环节时会念一句
「反应环节。按 F3 可以自动通过。」（不打断正在念的剧情，之后可以按退格重读）；
一直没通过的话，每 20 秒提醒一次，每局最多提醒 3 次；
结束时念「反应环节结束。」并带上抓到的修正值；4 秒内又出现则念「反应环节重新开始。」。

**默认也是「手动模式」，可以用键盘打。** 自动通过关着时，反应环节里：

- 第一颗按钮出现时会念「反应环节，手动模式：按回车拍按钮，上下键换目标，F3 可自动通过。」；
- `↑` / `↓`（`Home` / `End` 首末）在**当下出现的按钮**之间选择，每移动一次念「第 i 个，共 N 个」；
- 按 `回车` / `空格` / 小键盘回车，就按下当前选中的那个按钮；
- 每颗按钮出现后还有一声「按」的节拍提示（按钮凝实到阈值时），提醒你可以拍了。
  还没有按钮时按回车，会念「还没有出现按钮。」。

**手动是按「当下出现的按钮」点，不是提前点固定位置**——听着提示抓时机即可。
`F3` 仍可随时开 / 关自动通过（见下）。

**`F3` 任何一局都有效**（不受配置里「自动通过」开还是关影响）：

- 正在反应环节：按一下开启自动通过，念「自动通过已开启。」；再按一下关闭，念「自动通过已关闭。」。
- 不在反应环节：按一下只会说明用法——「当前没有反应环节。反应环节出现时，按 F3 可以自动通过。」

**自动通过打开后**，补丁会**等按钮出现约 1 秒再点** —— **实测 97%**（刚露头就点只有 50%）。
这个功能不会让局面变坏：错误选项点了无事发生、没有扣分，所以「把出现的按钮都点一遍」
在结果上严格优于「什么都不点」。采集范围严格限制在 QTE 面板子树内，不会误碰别处的按钮。

> 按 `F3` 切换的是**本次运行**的状态，不会写回配置；下次启动仍以配置里的
> 「自动通过」为准（默认 `false`）。想每局都自动通过，把配置改成 `true`。

> 旧版（0.1.x）这里是「默认自动点击」；本版按玩家反馈改成默认关闭——
> 自动辅助破坏这一段的沉浸感，用不用应该由玩家自己决定。

### 滑条与音量

设置界面的三条音量（BGM / 音效 / 语音）和文字显示速度都是滑条：

- 左右方向键每次调 5%；念「标签，滑条，新值，共 100%，每次 5%」。
- 按住左右键约 0.45 秒后开始连续调整（每 0.12 秒一次），不必按二十次。
- 到顶/到底会念「已到顶。」；每次调整都会打断上一句朗读，所以连按时听到的永远是最新值。
- 非 0–1 范围的滑条（例如标题画面那条隐藏的成就滑条，标签是「标题画面滑条」）
  会念成「50%（0.75 / 1.5）」这样，避免念出会误导人的整数。
- **不可用的滑条**（彩蛋设置视图整屏不可用、载入进度条）按左右键只会听到
  「该项当前不可用。」，**不会偷偷改值**。

> 0.1.x 里标题画面那条滑条会念出 `Image_Title` 这类英文对象名，本版已修，改为「标题插画显隐」。
> 0.2.1.0 起标题画面的按钮与这条滑条合并在**同一页**，方向键能走到它；
> 它只控制标题插画的溶解/显隐外观，**不影响 Konami 成就**（RE 已核对代码路径）。

## 装之前

- **NVDA**（推荐）：补丁会自动用 NVDA Controller Client，延迟最低、不会和语音重叠。**NVDA 必须先启动**。
- 没有 NVDA 也行：会自动退到 **Tolk**（若 `Tolk.dll` 在场，可支持 JAWS / SuperNova / ZoomText），
  再退到**争渡读屏（ZDSR）**，最后是 **Windows SAPI**。
  **争渡这一级不需要你做任何事** —— 补丁会先读 Windows「卸载」登记项里的
  `InstallLocation`（`DisplayName` 含「争渡」或 `zdsr` 的那些）**自动找到争渡的安装目录**，
  装在别的盘、装到自定义目录也算数；找不到再试默认位置。
  搜索顺序：**注册表登记的安装目录 → 默认安装目录 → 插件目录（包内兜底那份）→ 游戏目录**，
  安装目录里那份**永远优先**。本 zip 的 `BepInEx\plugins\` 里**另外带了
  `ZDSRAPI_x64.dll` / `ZDSRAPI.dll` 两份可删的兜底**（见下面「关于那两个 dll」）。
  要求争渡**正在运行**、且是**商业版 / 青春版**：
  公益档没有 API 权限，会被**如实判为不可用**。想固定用它，把配置「语音后端」填 `争渡`。
- 用 SAPI 兜底时，**系统里要装有中文语音**，否则中文念不出来。检查方法：`Win + Ctrl + N` 打开「讲述人」设置，或「设置 → 时间和语言 → 语音」。

### `[朗读]`

**`启用 = true`**
总开关。关掉则完全不朗读（界面操作、QTE 那些也一并停用）。

**`有配音时不再朗读 = true`**
命中配音白名单的行**完全静默**：不念正文、不报角色名、也不进重读缓冲
（0.2.1.0 起的固定行为，退格也读不到）。
本作 1502 条对话里 884 条有配音（**只有一部分角色有完整配音**，约 86~93% 的覆盖率）。
> 说明：当前版本的朗读策略固定为「有配音就完全静默」，所以这一项**暂时没有实际效果**；
> 保留配置项是为了以后调整策略（例如改成配音 + 文本一起放）。

**`播报说话人 = true`**
朗读**无配音**台词前先报名字（`国王：……`）。旁白不报。
**没有配音的说话人有三十多个**，不报名就分不清谁在说话 ——
明眼玩家看得见名牌，读屏玩家看不见。

**`有配音时也报名 = true`**
> 说明：0.2.1.0 起有配音的剧情行完全静默，**角色名也不报**，所以这一项
> 当前同样**不起作用**；保留配置项，等后续朗读策略调整。

**`朗读纯省略号 = false`**
`……` 这种只有标点的行是否也读出来。默认不读。

**`只朗读正在显示的行 = true`**
★ 剧透闸门，**强烈建议保持开启**。
`RevealableText` 是复用的，游戏会在面板还没显示时就把文本写进去
（载入存档 / 加载场景 / 预载剧本都会）。只挂 `set_Text` 的话，
这些玩家根本看不到的文本会被念出来 ——
**实测在 load 场景念出过玩家当时完全不该听到的内容。**
开启后只朗读同时收到「开始打印」事件、并且面板确实可见的行。

**`不经过打印器也朗读的面板 = SettingsUI`**
★ 逗号分隔的路径片段。命中这些面板的文本，**没有「开始打印」事件也朗读**。
为什么需要这一条：设置界面里那些随光标变化的解说文字是直接写进 `RevealableText` 的，
Naninovel 的 `OnPrintTextStarted` 根本不触发；只挂打印事件的话，这些字会被上面那道
剧透闸门一律拦掉（实测日志：`REVEAL 拦下（没有打印事件…）欢迎来到——莉莉丝的设置界面~`）。
放行的前提仍然是**面板此刻确实可见**（第二道闸门照旧生效），所以不会放松剧透防护。
留空可停用。

**`朗读笔记本（假回想） = true`**
剧情里「打开笔记本」那一段。★ 它**也不是对话**：剧本里是 `@FakeBackLog` 命令把游戏的
**假回想面板**（`BacklogFakeUI` / `BackLogFakePanel`）摊开，既没有打印事件、
也不是 `RevealableText`。开启后按画面节奏念：滚进可见区的每条念一次，用排队而不是打断。
它也进了「可导航文字的界面」的默认名单，所以打开后方向键逐条翻、回车重念当前这条即可。

**`按说话人当成有配音 = 莉莉丝,???`**
★ 逗号分隔的关键词。**说话人名（或游戏里的说话人 id）里含这些词的行，一律当成有配音**：
按「有配音」处理，也就是**完全静默**——不念文本、不报角色名、不进重读缓冲。
为什么要有这一条（作者定的「暴力」口径）：行号白名单是按**行号**对的，难免有漏 ——
漏一条的表现就是「这一句明明有语音，读屏却又念了一遍」。按**人**过滤不会漏：
本作有配音的就是莉莉丝（含她的各种名号）与 `???`，配角 / 道具都没有配音，照念。
代价：万一某句莉莉丝的台词其实**没有**配音，这句的文本就**完全听不到**了 ——
0.2.1.0 起有配音的行不朗读、不报名字、也不进重读缓冲，**按退格也读不到**。
所以这份名单要保守，别把没配音的角色写进去。留空可停用。

**`播报「笔记本图像」 = true`**
剧情里翻到笔记本**纸页**时念一句「笔记本图像」。
那一页是**图片**（剧本用 `@ModifyBackground diary1`~diary4 把整页纸换上来），
纸页上的手写字**不在游戏数据里**——实测把 4945 个文本对象逐个扫、再把两个数据文件
按原始字节扫（417MB + 2142MB），特征短语 **0 命中**，字是画进图里的。
所以这里只能做一件诚实的事：告诉你「画面上出现了一张图」，**内容请用读屏软件的 OCR 功能看**。

> 别和**假回想面板**（`@FakeBackLog` 打开的 `BacklogFakeUI`）弄混：
> 那个是**文本**，补丁会念，打开时也能用方向键逐条翻。

**`语音后端 = 自动`**
`自动` / `NVDA` / `Tolk` / `争渡` / `SAPI`（`争渡` 与 `ZDSR` 两种写法都认）。
默认按 **NVDA → Tolk → 争渡 → SAPI** 的顺序挑第一个可用的
（与 TransparentHer 的 Tolk 优先不同 —— 本作以 NVDA 为一等公民）。
钉死某一个主要用来排查问题，例如填 `SAPI` 就能确认系统语音这条路通不通；
注意钉死之后**不会自动降级**，那个后端不可用就彻底没声了。

`争渡` 这一级用的是争渡自己的语音接口，听到的是**你读屏本人的声音**而不是系统语音。
判据是 `GetSpeakState()` ∈ {3（正在朗读）, 4（空闲）} —— **不是** `Speak()` 的返回值：
未授权时 `Speak()` 照样返回 0，拿它当判据会「日志一片绿、耳朵一片安静」。
公益档下 `GetSpeakState()` 恒为 2，会被**如实判为不可用**（这是授权模型，不是 bug）。

**关于那两个 dll（`BepInEx\plugins\ZDSRAPI_x64.dll` / `ZDSRAPI.dll`）**

它们**不是我们的东西**，是**争渡读屏**的 API。随包只为**兜底** ——
给那些在自己机器上翻不到这个 dll 的人。

- 补丁优先用你**争渡安装目录**里那份（官方建议：那份会跟着读屏一起升级）。
  只有当注册表与默认位置都找不到时，才用到包内这份。
- 包内这份是**打包机**上的版本，可能比你本机的争渡旧。**旧了也不要紧**：
  补丁发现它报「版本不匹配」（`InitTTS` 返回 1）时会**自动换下一份候选**，不会卡住你。
- **想删就删。** 删掉这两个文件后补丁回到「只读争渡安装目录」，功能不变。
- 我们**未经修改**地原样再分发它们，用途限于这个**免费、非商业**的补丁；
  依据是争渡官方 API 文档自己写的那句「应用程序……或者直接把 dll 复制到
  指定的目录调用均可」。我们与争渡官方**没有隶属关系，也没有取得书面许可**；
  如果争渡的作者认为不妥，请联系我们，会立刻移除。
  完整署名见包内 `licenses\THIRD-PARTY-NOTICES.txt` 的组件清单。
- 本包**不带 `ZDSRAPI.ini`** —— 那个文件是给玩家自己覆盖通道设置用的，
  随包带一份反而会覆盖你已经写好的选择。
- **想确认当前用的是哪一份**：看日志里 `语音后端: 争渡读屏（ZDSR），DLL=…`
  那个路径。指向争渡安装目录＝用了安装目录那份；指向 `BepInEx\plugins\`
  ＝用了兜底那份。
- **想手动指定目录**（一般用不到）：设环境变量 `A11Y_ZDSR_DIR`，可写多个目录、
  用 `;` 分隔；一旦设置就**只找它列出的目录**。这是排查用的开关。

**`切换语音后端按键 = F9`**
运行中按一下切到下一个**当前可用**的后端 —— 不必改配置、不必重启游戏。
循环顺序固定为 `自动 → Tolk → NVDA → 争渡 → SAPI`；当前不可用的会被**跳过**，
并在播报里说明跳过了谁。选择会**写进本配置文件**，下次启动仍然生效。留空可停用。
配置是「自动」时，这一档按**当前实际在用的后端**算位置：NVDA 在跑时按第一下就落到争渡
（否则第一下切到的还是 NVDA，会让人以为这个键没生效）。
循环只向前走，所以 NVDA 在跑时这个键**够不到 Tolk**（Tolk 排在循环里的 NVDA 前面）——
想用 Tolk 就直接把「语音后端」填成 `Tolk`。
可以写修饰键组合，例如 `Alt+Shift+F9`、`Ctrl+Alt+F9`；**修饰键必须完全对上**；
纯数字键名会被拒绝，要数字键请写 `Alpha0`。

**`重读键 = Backspace`**
界面操作接管时，退格重读**当前这一项**；没接管界面时，重读**最近一次可以朗读的内容**。
与 TransparentHer 一致：**不回溯**，只重读最近一次。
**0.2.1.0 起重读缓冲收窄**：只保存**未配音的剧情正文**和**整组选项**。
- 有配音的剧情行**不进缓冲**：它本来就不朗读，退格也读不到（避免把配音台词又念一遍）。
- QTE、加载提示、字幕、界面播报**一律不占用重读**，退格不会突然念出这些。
「一段」而不是「一句」：选项算重读对象 —— 整组选项拼成一段
（`共 N 个选项。选项 1：…。选项 2：…。按数字键选择。`），
所以选项出现后按退格能把整组再听一遍，不用凭记忆回想有几项。
记忆只在内存里，退出游戏即清空。想往回翻更多，去回想（History）界面逐条走。留空可停用。

**`沉默键 = 0`**
按一下立刻让朗读闭嘴（相当于 TransparentHer 的「沉默按键」）。
默认 `0` —— 剧情里用不到数字键，不会和选项冲突
（选项的数字键只在选项框出现时生效）。留空可停用。

**`新台词打断上一句 = true`**
与 TransparentHer 一致（`Say(text, interrupt: true)`）。
开着时每来一句就取消正在念的那句：读得激进，但朗读不会滞后于画面。
长句没念完被打断，按「重读键」即可翻回来；嫌啰嗦就按「沉默键」。
关掉则改为排队等上一句念完 —— 一个字都不丢，但朗读会滞后于画面。

**`撞上配音时清空待读队列 = true`**
只在「新台词打断上一句」关掉（=启用排队）时才有意义。
排队时若这一句要放角色语音，TTS 会和语音叠在一起、两边都听不清，
所以默认为角色语音让路。

**`朗读「正在加载」= true`**
加载时念一句「正在加载。」读屏玩家在加载期间完全不知道游戏在干什么 ——
没画面可看、没声音可听，很容易以为卡死了然后去乱按。
两条通路都认：Naninovel 的 `LoadingPanel`，以及名字里带 `load` 的 Unity 场景。
**会打断**正在念的那句：这条提示回答的正是"为什么没反应"，晚说几秒就完全失去意义。
被它打断的那句按「重读键」翻回来即可。

> ⚠️ 从按下按钮到游戏把加载画面显示出来，中间游戏自己还要切场景、预载资源，
> **这段时间屏幕上什么都没有**，补丁无从得知。所以听到「正在加载」总会比按键晚几秒，
> 那是游戏的静默期，不是补丁在犹豫。

**`朗读字幕 = true`**
剧本里的 `@subtitle` 字幕（片尾 / 唱歌 / 伪 ED）。
★ 这条**不是**走对话打印器的：`SubtitleUI` 播一段 Animation，文字写在预制体里的
TMP 节点上，既没有 `RevealableText` 也没有打印事件 —— 只挂打印器的话这段**一个字都不念**。
开启后按画面节奏念：滚进可见区的每一行念一次，同一行的左/中/右几格拼成一句，
用排队而不是打断。

### `[QTE]`

**`自动通过 = false`**
★ 本版**默认关闭**。关闭时只播报、绝不代点：进入反应环节念
「反应环节。按 F3 可以自动通过。」，一直没通过每 20 秒提醒一次（每局最多 3 次）。
想跳过这一段时，自己按 `F3`。打开后补丁会等按钮出现约 1 秒再点——实测 97%
（刚露头就点只有 50%）；错误选项点了无事发生、没有扣分，采集范围严格限制在
QTE 面板子树内。

> 为什么默认关：自动通过是"替你操作"，会破坏这一段的沉浸感，也让想看修正值上限的
> 玩家失去选择权——要不要用由玩家决定。这是 0.2.0.0 与旧版最大的行为差别。

**`开关热键 = F3`**
在反应环节里切换「自动通过」的按键，切换时会念出当前状态。
★ **无论上面那一项是开是关，这个键都有效**，任何一局都能按；
不在反应环节按会说明用法（不会报错）。
填 Unity 的 KeyCode 名，例如 `F3` / `F4` / `BackQuote`。
（写空或写错会回退到 `F3`，所以这个键实际上是关不掉的——不想用时别按即可。）

**`兜底延迟（秒） = 1.0`**
★ **这就是实际生效的那个旋钮。** 实测（v0.0.0.4 日志）：按钮的渐隐不是靠
`CanvasGroup` / `Image.color.a` 做的，补丁读不到 alpha 变化，所以「按峰值点」那条路
100 次里只触发了 1 次——真正起作用的就是这个延迟。1.0 秒 = 97%。
想冲 100% 可以试 1.2~1.5，但调太大有漏点的风险。

### `[界面操作]`

**`启用键盘操作 = true`**
打开时：游戏菜单一出现，键盘直接可用——**不需要先按任何键进入「导航模式」**。
上下方向键选项，回车/空格激活，左右方向键调整滑条，退格重读当前项。
菜单关掉后键盘自动交还游戏；uGUI 的键盘导航/提交通路**只在接管期间关闭、退出即还原**。
关掉后本模组完全不碰界面键盘，行为与没装本模组一致。

**`只操作画面上可见的控件 = true`**
只排除「画面外」和「`CanvasGroup` 隐藏」的控件；**看得见但被装饰 / 穿透层挡住的控件不再排除**
（游戏按钮的 `onClick` 本来就不看射线 —— 0.2.1.0 起画廊、Tips 的返回按钮因此不再被藏起来）。
因为 Naninovel 的面板靠 `CanvasGroup` 显隐，光靠 `activeInHierarchy` 是拦不住的。
关掉这一项会把画面外的隐藏控件也收进操作列表，一般不要关；只有正常按钮被误排除时才关。

> **整屏控件都不可用时怎么办**：本作有些界面（典型的是彩蛋界面「莉莉丝的设置界面」）
> 游戏会把**全部**控件的 `interactable` 置成 `false`。这种屏会改为**只读纳入**：
> 把这些看得见但点不动的控件也念出来（标签后面带「不可用」），进入时先提示
> 「这一屏的控件当前都不可用，只能听，不能选」，按回车只会听到「该项当前不可用。」。
> 原则没变：无障碍层只让本来就看得见的东西变得**听得见**，
> 不让任何本来点不到的东西变得可点。

**`按屏幕位置排序 = true`**
操作顺序按控件在屏幕上的位置排（先上后下、同一行先左后右），
让「第几项」和画面对得上。关掉则改回按渲染层级排序——那样顺序和画面就对不上了，
除非你有特别理由，否则别关。

**`可导航文字的界面 = BacklogUI,BacklogFakeUI`**
★ 逗号分隔的路径片段。命中这些界面时，**纯文本也会变成可操作项**。
用途：回想（History）面板里每条台词是一个纯文字，没有对应的控件。
纳入之后：方向键逐条翻、回车**重念当前这条**——
「重读上一句」和「回想朗读」一次解决，而且用的是游戏本来就有的交互。
按钮/开关自带的标签会自动跳过，不会重复念。留空可停用。

**`对话界面按钮热键 = Alt+M`**
剧情对话时，屏幕上的「设置」「回想」按钮游戏只留了鼠标入口（这是本作的界面设计）。
按这个键进/出「对话界面按钮」页。
★ **实验性辅助链路（已随 2026-11-22 正式版实测通过；失败会播报并写日志）**：游戏在纯键盘剧情期通常不创建这个 HUD。补丁会尝试
让引擎创建并显示它（最多等 1.5 秒、每 0.2 秒重扫）：成功念「正在打开对话界面按钮。」
并列出游戏当前可用的按钮；失败念「没能打开对话界面按钮。」，失败原因写进
`BepInEx\LogOutput.log`、前缀 `[UiNav] HUD：`（这一行**不受「详细日志」开关影响**）。
如果是补丁创建的 HUD，退出这一页时补丁会把它隐藏。
★ **只在这个场景用**：菜单等其他界面会自动接管，不需要按键。
留空可停用。

**`非菜单界面（不自动接管）= ControlUI,SubtitleUI,CustomSkipUI,QTEPanel,ChoiceHandler,ClickThrough,LoadingUI,MovieUI,TransitionUI,EraseUI,Phone`**
★ 逗号分隔的路径片段。这些是「不是菜单」的界面：对话 HUD、字幕、跳过提示、
载入画面、过场、涂抹小游戏、选项框、手机。它们不自动接管键盘：
没有可选项，而且回车/空格要留给游戏推进剧情、数字键选选项、`F3` 过 QTE。
（选项框出现时，方向键浏览与回车确认由选项模块单独处理，见上面「选项框」。）

**`退出前二次确认 = true`**
「退出游戏」只按一下就关掉整个会话，而读屏用户分不清它和旁边的按钮，
所以补一道确认：第一次回车只是问一句，再按一次才真的退。

**`退出按钮对象名 = ExitButton,QuitGame,ExitGameButton,QuitButton`**
哪些控件需要上面那道确认，按 Unity 对象名**精确匹配**，逗号分隔。

**`排除的面板路径 = ScriptNavigatorUI,ExternalScriptsBrowser,DebugInfoGUI,CustomVariableGUI,SaveLoadUI`**
逗号分隔的路径片段，命中就不纳入操作。默认排掉的是 Naninovel 自带的

- `ScriptNavigatorUI` —— 「直接跳转到任意剧本」面板，里面是

  实测结果是黑屏 + 有音乐 + 无任何响应，只能 Alt+F4。
  **这是实测踩过的坑，不是理论风险。**
- `SaveLoadUI` —— 本作故意不提供存/读档界面，但引擎那整套都在

- 其余三个是同类调试面板。

### `[诊断]`

> 这一段是给排查问题用的，**正常游玩保持默认即可**。

**`隐藏控制台窗口 = true`**
装完第一次启动时，游戏旁边会闪出一个黑色命令行窗口 —— 那是 BepInEx 的日志窗口。
补丁在**运行时**把它藏掉（`GetConsoleWindow` + `ShowWindow`），正常情况下你看不到它。
真想看实时日志就把这一项关掉。
**日志文件一直都在** `BepInEx\LogOutput.log`，藏不藏窗口都照写，诊断能力一点没少。

**`详细日志 = false`**
把每句判定和界面扫描等诊断写进 `BepInEx\noexistence_a11y.log`。
**0.2.1.0 起默认关闭**：实测一次会话 10MB 日志里 84.7% 是界面扫描的完整清单，
是之前卡顿的主要来源。出问题排查时再打开；打开后也最多每 10 秒写一份清单、
只在状态变化时写（每轮仍有一行统计）。

**`自动开始游戏 = false`** / **`自动推进剧情 = false`**
测试用。打开后引擎就绪时会自动点掉标题画面的 START，
并让剧情自己往下走。**正式游玩保持关闭。**

**`跳转脚本 = （空）`** / **`自动跳转 = false`** / **`转储剧本行表 = false`** / **`跳转位置 = 0`** / **`跳转热键 = （空）`**
★ 诊断功能，**默认全部关闭**（跳转脚本留空 = 不跳转）。
填上「跳转脚本」（例如 `Prologue1_6`）后，在游戏里按热键就能直接跳到那个剧本的
**开头**播放；「跳转位置」是从第几行开始播，默认 0（从开头）。
用途：QTE 在第一章末尾，进度过了就够不着、没法回头验证功能；
跳过去之后按住 `Ctrl`（Naninovel 的跳过键）可以几秒冲到目标位置。
「自动跳转」= 不按热键、引擎就绪后自动跳一次；「转储剧本行表」= 每次跳转时把
该剧本的行表写进日志，方便查出要跳的行号。这三个都只写日志或改变播放位置。

> **关于「跳转热键」的一个实现细节**：这一项留空时，代码里实际会回退成 `F4`。
> 也就是说填了「跳转脚本」之后，不填热键也可以按 `F4` 触发；
> **真正关掉诊断跳转的办法是把「跳转脚本」留空**。
> 普通玩家不要填「跳转脚本」——它会让游戏从别的剧本开头播起来，
> 而本作**没有存档/读档界面**，跳错了回不去。

`跳转位置` 默认 0：从开头播时，脚本自己的 `@char` / `@modifyCharacter` 立绘装配命令
都会执行；从中间起播会**跳过**它们，实测角色立绘直接错乱（当初玩家原话「拼图错误」）。

> ⚠️ 会打乱正常流程，而且游戏会自动存档。用之前先备份 `Saves` 目录
> （位置见下面「关于存档」）。
> 另外：**不要试图改存档的 `playbackSpot` 跳到剧本中间** ——
> 那会跳过立绘分层装配命令，角色立绘会直接错乱。这条也踩过。

#### 测试者：快速跳到指定位置

> 这一小节是**开发者后门**，只给做测试 / 验收的人看。
> **正式游玩把「测试模式（开发者后门）」保持 `false`。**

想直接看某章结尾、某个 QTE 或特殊控件，把 `[诊断]` 里这几项一起填上：

| 配置项 | 例子 | 说明 |
|---|---|---|
| `测试模式（开发者后门）` | `true` | 引擎就绪后自动点标题 START，并自动按「跳转脚本 / 跳转位置」跳一次；**正式游玩必须改回 `false`** |
| `跳转脚本` | `Prologue6` | 要跳的剧本名；不知道名字就先随便填一个再跳，日志会列出内存里所有剧本名与行数 |
| `跳转位置` | `-15` | **负数 = 倒数第 N 行**：`-15` 表示从剧本末尾往前数第 15 行开始播；`0` = 从头；正数 = 从第 N 行开始 |
| `转储剧本行表` | `true` | 每次跳转时把该剧本的**完整行表**写进 `BepInEx\noexistence_a11y.log`，方便查行号 |
| `转储全部剧本行表` | `false` | 测试者用：引擎就绪时把内存里**所有剧本**的行表写进同一份日志（独立生效，不需要打开「转储剧本行表」） |
| `跳转热键` | `F4` | 游戏里随时按它重新跳一次（留空时实际回退 `F4`） |

- 「测试模式」只负责自动开始 + 自动跳一次；**剧情要不要自己往下走由「自动推进剧情」单独控制**——测试特殊控件时建议把它关掉，免得冲过头。也可以不开测试模式，只打开「自动跳转」，或在游戏里按「跳转热键」手动触发。
- 用行表找行号：打开「转储剧本行表」（想一次看全部就再开「转储全部剧本行表」）→ 触发跳转 → 到 `BepInEx\noexistence_a11y.log` 里搜 `SCRIPT 行表`：每条是 `[行号] 类型  @命令名/#标签  行哈希  原文`；找到想看的那一行，把行号填进「跳转位置」（想从末尾数就填负数）。行表很长，用文本编辑器的搜索找台词原文更快。
- 找不到剧本时，日志会列出内存里所有剧本名与行数（例如 `Prologue6(1234行)`），照着改「跳转脚本」。
- ⚠️ 跳转会**打乱正常流程**、游戏也会**自动存档**：先备份 `Saves` 目录（位置见下面「关于存档」）；从中间行起播会跳过立绘装配命令，可能立绘错乱。测完把「跳转位置」改回 `0`、「测试模式」和两个「转储」项改回 `false`。

### ⚠️ 有一件事补丁帮不上：笔记本的「纸页」

抄进仓库就违背了「本仓库不含任何游戏资源」这条底线）。

> 另外别把两件事混起来：**「假回想面板」**（剧本里 `@FakeBackLog` 打开的
> `BacklogFakeUI`）是**文本**，补丁会念，打开时也能用方向键逐条翻 —— 那是另一条通路。

### ⚠️ 关于存档

**这个游戏没有存档 / 读档界面**——游戏里只有 `History` 和 `Options` 两个按钮，主菜单只有「继续游戏」。这是设计如此。

但**引擎层的自动存档是存在的**，在：

```
%USERPROFILE%\AppData\LocalLow\Nino\TheNOexistenceNofyouANDme\NaninovelData\Saves\
    1.json            ← 自动存档槽（进度就存在这里）
    GlobalSave.json   ← 全局变量与解锁状态
```

「继续游戏」读的就是它。**如果你要用诊断跳转做实验，先把这个目录整个备份** ——
跳过去之后游戏会把新位置写进自动存档，原来的进度就没了。

## 出问题时

**从 Steam 启动后没声音 / 补丁像没装。**
这多半是 **Steam 会话被 Doorstop 环境变量污染**，不是装错了：别的 Doorstop 模组的
注入链会把 `DOORSTOP_DISABLE=TRUE` 带进 Steam 会话，游戏进程再继承它；如果
`doorstop_config.ini` 里 `ignore_disable_switch = false`，Doorstop 就会**直接跳过注入**，
BepInEx 和本补丁根本不会加载 —— 这时 `noexistence_a11y.log` 里连一条 `[boot]` 都不会有。
本补丁（0.2.1.0 起）已把游戏目录和发布包里的 `doorstop_config.ini` 改为
`ignore_disable_switch = true`，部署脚本 / 发布脚本也会自动写这个开关，正常覆盖安装即可免疫。
如果还是没反应，**把 Steam 彻底退出（右下角托盘里右键退出，不是关窗口）再重新启动**；
这一步也能顺带清掉其他被同一环境变量污染的模组游戏。
排查顺序：
1. `BepInEx\LogOutput.log` 里有没有 BepInEx 自己启动加载的那几行（Chainloader 之类）；
2. `BepInEx\noexistence_a11y.log` **开头有没有 `[boot] ...` 行** —— 有就说明补丁在跑
   （问题只在朗读链路），没有就说明**补丁根本没加载**。
   `[boot]` 行不受「详细日志」开关影响，始终会写。

**一点声音都没有。**
先确认 NVDA 已经开着（用争渡的话：争渡在跑、且是**商业版 / 青春版**），
再看 `BepInEx\noexistence_a11y.log` 头两行。会写明用了哪个后端；
若写着「没有可用的语音后端」，后面会跟每个后端的失败原因。
也可以**按 `F9`** 在运行中换一个当前可用的后端试试。

**念到某句突然没声了。**
那一句多半是**有配音的**——补丁故意让游戏语音说话，避免两路声音打架。
日志里对应行是 `voiced=True`。

**为什么有人的名字念出来是「未知」？**
游戏把一个名字显示成了三个问号（`???`）。补丁**按游戏显示的原样念**，
不去猜那是谁、也不会拿别的名字替上去 —— 名字本身可能就是剧情的一部分。

**菜单里按方向键没反应 / 不知道光标在哪。**
先确认配置「启用键盘操作」是开着的。0.2.1.0 的接管时机是：
每 0.35 秒扫一次，**同一个界面连续两次扫描（间隔至少 0.2 秒）才接管**，
所以菜单淡入后大约半秒内可用，按早了会没反应，再按一次即可；
接管后 0.8 秒内不会播「界面已更新」，那是故意的（避免只扫到半屏就报）。
如果最上层是**被排除的界面**（存档 / 读档、开发者面板等），补丁**故意不接管** ——
防止回车点穿到背景按钮上，这不是坏了。
还不行就看 `noexistence_a11y.log` 里 `[UiNav]` 开头的行，会写扫描到几个控件、
为什么被筛掉；该日志默认 `详细日志=false`，排查时先打开。

**按 `Alt+M` 没反应，或听到「没能打开对话界面按钮」「当前没有可以操作的界面按钮」。**
这是预览版起、正式版沿用的**实验性辅助链路**（2026-11-22 实测通过）：游戏在剧情期可能根本没有创建
对话界面按钮（HUD）。EXP2 起任何页面按 `Alt+M` 都会先交还当前页面，再尝试让引擎创建并显示
HUD，最多等 1.5 秒、每 0.2 秒重扫；如果听到「当前没有可以操作的界面按钮。」是在重试中，
最后仍打不开会念「没能打开对话界面按钮。」——**不影响剧情，也不影响其他菜单**。
排查请把 `BepInEx\LogOutput.log` / `BepInEx\noexistence_a11y.log` 发给我们，搜 `[UiNav] HUD：`
开头的那几行（这一行不受「详细日志」开关影响，默认也会写）。

**选项没念出来 / 选项选不中。**
选项出现时补丁会自动整组朗读，**用 `↑` `↓` 浏览、回车或空格确认**，按 `1`–`9` 也能直接选；
如果某一项按数字键、方向键都没反应，多半是游戏把那一项标成了不可用（补丁只点"此刻可点"的项）。
看日志里 `CHOICE` 开头的行。选项整组可以用退格重读。
**如果发现「听到的」和「选中的」不一致**：EXP1 及更早有过这种情况，EXP2 已修
（选项面板出现时临时关闭 uGUI 的键盘提交，关闭后原样还原，两种选法都会先复述标签再点）。
还遇到请把日志里的 `CHOICE 已关闭 uGUI Submit` / `CHOICE 已还原` 行一起发回来。

**QTE 没有自动过。**
0.2.0.0 起**默认就不自动**：这是设计，不是坏了。
想跳过时按 `F3`（会念「自动通过已开启。」）；不在反应环节按 `F3` 只会说明用法。
想自己打也可以：EXP2 起支持手动模式——`↑` `↓` 选按钮、`回车` / `空格` 按下当前按钮，
每颗按钮出现时有一声「按」的节拍提示（详见上面「反应环节（QTE）」）。
如果连提示都听不到，看日志里 `QTE` 开头的行。

**黑色控制台窗口跑出来了。**
默认是藏起来的。跑出来说明「隐藏控制台窗口」被关掉了，
或者这个窗口属于**别人**的 BepInEx 模组（那就得去改对方或 BepInEx 自己的配置）。
本补丁这一项在 `BepInEx\config\noexistence.a11y.cfg` 的 `[诊断]` 里。
真想彻底关掉 BepInEx 的日志窗口：`BepInEx\config\BepInEx.cfg` →
`[Logging.Console]` → `Enabled = false`。日志文件照常写。
