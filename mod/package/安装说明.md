## 这个补丁做了什么

**读台词。** 对话、旁白、章节标题、ED 字幕全部朗读。有配音的台词只放游戏语音、不重复念；没配音的用 TTS 念，并且**先报说话人名**。

**读选项。** 本作主角**从不用文本说话**——她/他的全部台词都在选项框里，全剧 625 条以上、8000 多字。补丁会在每条选项出现时带序号念出来。

**能不用鼠标玩。** 原本选项只能用鼠标点，标题画面那个「/」要拖动。现在：

| 按键 | 作用 |
|---|---|
| `Tab` | 进入 / 退出界面导航模式 |
| `↑` `↓` | 上一个 / 下一个控件（会念出它是什么） |
| `←` `→` | 调整滑条 |
| `回车` / `空格` | 激活当前控件（导航模式外，回车和空格照常推进剧情） |
| `1` – `9` | **选项出现时直接选第 1–9 项**，不必用鼠标、也不必先进导航模式 |
| `PageUp` / `PageDown` | 切换面板组（比如设置页签） |
| `Home` / `End` | 第一项 / 最后一项 |
| **`退格`** | **重读最近朗读过的那一段**。剧情台词、以及**选项**都算重读对象 —— 选项出现后按退格会重读**整组选项**。记忆只在内存里，退出游戏即清空 |
| **`0`** | **沉默键**：立刻让朗读闭嘴。默认 `0`——剧情里用不到数字键，不会和选项冲突 |
| **`F3`** | 开关 QTE 自动点击（切换时会念出状态） |
| **`F4`** | **默认关闭。** 诊断用：跳到配置指定的剧本开头，配合按住 `Ctrl` 快进。要用得自己在配置里填 |

**自动通过 QTE。** 剧情里有一处限时反应小游戏（在 `Prologue1_6` 剧本里）：按钮散落在屏幕上、**透明→最实→渐隐消失**，得分取决于**点击瞬间按钮的凝实程度**，低于阈值要重来。画面上没有任何可听的线索，盲人玩家不是玩得差，是根本没有可玩的通道。

补丁会**等按钮出现约 1 秒再点** —— **实测 97%**（刚露头就点只有 50%）。随时按 `F3` 开关，想手动对照很方便。

> 这个功能不可能让局面变坏：错误选项点了无事发生、没有扣分，所以「把出现的按钮都点一遍」在结果上严格优于「什么都不点」。采集范围严格限制在 QTE 面板子树内，不会误碰别处的按钮。

**ruby 双读。** 本作的 `<ruby>` 旁注**不是注音**，而是一层独立的内容 ——
正文和旁注都写着字，只读一个就会漏掉另一个写的东西。
补丁两个都读并标注，例如：

```
本年度最受期待的剧情向角色扮演（实为：RPG）游戏！
```

## 安装

### 前置

- **NVDA**（推荐）：补丁会自动用 NVDA Controller Client，延迟最低、不会和语音重叠。**NVDA 必须先启动**。
- 没有 NVDA 也行：会自动退到 **Tolk**（若 `Tolk.dll` 在场，可支持 JAWS / SuperNova / ZoomText），再退到 **Windows SAPI**。
- 用 SAPI 兜底时，**系统里要装有中文语音**，否则中文念不出来。检查方法：`Win + Ctrl + N` 打开「讲述人」设置，或「设置 → 时间和语言 → 语音」。

### 步骤

**把压缩包里的东西全部拷进游戏根目录就行。没有安装程序。**

1. 在 Steam 里找到游戏 → 右键 → **管理 → 浏览本地文件**，打开游戏根目录。
   默认位置通常是：

   ```
   <Steam 库>\steamapps\common\The NOexistenceN of you AND me
   ```

   （进得去的话，你应该能在这个目录里看到 `TheNOexistenceNofyouANDme.exe`。）

2. 解压下载的压缩包。

3. **把解压出来的所有文件和文件夹，整个复制到游戏根目录**，提示"是否合并/替换"时选**是**。

   拷完之后游戏根目录应该长这样（只列补丁相关的）：

   ```
   The NOexistenceN of you AND me\
   ├─ TheNOexistenceNofyouANDme.exe
   ├─ winhttp.dll                    ← 新增
   ├─ doorstop_config.ini            ← 新增
   ├─ .doorstop_version              ← 新增
   ├─ changelog.txt                  ← 新增
   ├─ BepInEx\                       ← 新增
   │   ├─ core\
   │   └─ plugins\
   │       ├─ NoExistenceA11y.dll
   │       └─ nvdaControllerClient.dll
   ├─ dotnet\                        ← 新增
   ├─ licenses\                      ← 新增，**别删**（见下）
   ├─ 安装说明.md
   └─ 常见问题.md
   ```

   > **`licenses\` 里是第三方组件的许可证与声明，请不要删。**
   > 这个包里有二十来个第三方二进制（BepInEx 运行时、Il2CppInterop、
   > NVDA 客户端、.NET 运行时等），它们各自的许可证要求随包附上文本与版权行。
   > 其中 `LGPL-3.0-Il2CppInterop.txt` 与 `il2cppinterop-pr277.patch` 是必须带的两份 ——
   > 后者是那个被打过补丁的库的源码改动说明。
   > 它们不占地方（几十 KB），删掉不影响游戏运行，但会让这个包不合规。

4. **启动游戏**。第一次启动会慢一些（BepInEx 要按本机游戏生成适配层），
   之后就正常了。

5. 进游戏后随便点几句，读到台词就成了。

> **补丁不改动任何游戏文件。** 上面新增的那些都是旁挂的，
> 游戏本体一个字节都没动。

### 关于那个黑色控制台窗口

装完第一次启动时，游戏旁边可能会闪出一个黑色命令行窗口 —— 那是 BepInEx 的日志窗口。
补丁会**自动把它藏起来**，正常情况下你看不到它。
真想看实时日志（排查问题时），把配置里的「隐藏控制台窗口」关掉。
日志文件一直都在 `BepInEx\LogOutput.log`。

### 卸载

删掉上面"新增"的那些即可（都在游戏根目录）：

```
winhttp.dll
doorstop_config.ini
.doorstop_version
changelog.txt
BepInEx\
dotnet\
licenses\
安装说明.md
常见问题.md
```

只想去掉补丁、保留 BepInEx：删 `BepInEx\plugins\NoExistenceA11y.dll` 就行。

> ⚠️ 卸载后**不要**让游戏保留 `BepInEx\config\noexistence.a11y.cfg`——
> 那只是个配置文件，留着无害，但下次再装会沿用它。

### `[朗读]`

**`启用 = true`**
总开关。关掉则完全不朗读（导航、QTE 那些也一并停用）。

**`有配音时不再朗读 = true`**
命中配音白名单的行只放游戏语音，不再用 TTS 重复念一遍。
本作 1502 条对话里 884 条有配音（**只有一部分角色有完整配音**，约 86~93% 的覆盖率）。
关掉会变成「语音 + TTS 同时念」，一般只会更吵。

**`播报说话人 = true`**
朗读**无配音**台词前先报名字（`国王：……`）。旁白不报。
**没有配音的说话人有三十多个**，不报名就分不清谁在说话 ——
明眼玩家看得见名牌，读屏玩家看不见。

**`有配音时也报名 = true`**
同一个角色在剧情里会换名牌，而**声音是同一个人配的，光靠听分不出来**。
换名牌这件事本身是剧情的一部分，所以有配音时也把名字念一遍。
觉得吵就关掉 —— 代价是明眼玩家看得到的名牌变化，盲人玩家感知不到。

**`朗读纯省略号 = false`**
`……` 这种只有标点的行是否也读出来。默认不读。

**`只朗读正在显示的行 = true`**
★ 剧透闸门，**强烈建议保持开启**。
`RevealableText` 是复用的，游戏会在面板还没显示时就把文本写进去
（载入存档 / 加载场景 / 预载剧本都会）。只挂 `set_Text` 的话，
这些玩家根本看不到的文本会被念出来 ——
**实测在 load 场景念出过玩家当时完全不该听到的内容。**
开启后只朗读同时收到「开始打印」事件、并且面板确实可见的行。

**`不经过打印器也朗读的面板 = SettingsUI`**
★ 逗号分隔的路径片段。命中这些面板的文本，**没有「开始打印」事件也朗读**。

为什么需要这一条：本作有一部分正文**不是走对话打印器的** ——
设置界面里那些随光标变化的解说文字就是直接写进一个 `RevealableText` 的，
Naninovel 的 `OnPrintTextStarted` 根本不触发。只挂打印事件的话，
这些字会被上面那道剧透闸门一律拦掉（实测日志：
`REVEAL 拦下（没有打印事件…）欢迎来到——莉莉丝的设置界面~`）。

放行的前提仍然是**面板此刻确实可见**（第二道闸门照旧生效），
所以「藏在隐藏面板里的预载文本」这条老路依然堵着，没有放松剧透防护。
留空可停用。

**`朗读笔记本（假回想） = true`**
剧情里「打开笔记本」那一段。

★ 它**也不是对话**：剧本里是 `@FakeBackLog` 命令把游戏的**假回想面板**
（`BacklogFakeUI` / `BackLogFakePanel`）摊开，一条条列着已经发生过的句子，
既没有打印事件、也不是 `RevealableText` —— 只挂打印器的话这一段同样一个字都不念。

开启后按画面节奏念：**滚进可见区的每条念一次**，用排队而不是打断。
它也进了 `[界面导航] 可导航文字的界面` 的默认名单，所以想逐条慢慢看，
按 `Tab` 打开导航、方向键翻、回车重念当前这条即可。

**`语音后端 = 自动`**
`自动` / `NVDA` / `Tolk` / `SAPI`。
默认按 **NVDA → Tolk → SAPI** 的顺序挑第一个可用的
（与 TransparentHer 的 Tolk 优先不同 —— 本作以 NVDA 为一等公民）。
钉死某一个主要用来排查问题，例如填 `SAPI` 就能确认系统语音这条路通不通；
注意钉死之后**不会自动降级**，那个后端不可用就彻底没声了。

**`重读键 = Backspace`**
重读**最近朗读过的那一段**。与 TransparentHer 一致：不回溯，只重读最近一次。

「一段」而不是「一句」是有讲究的：**选项也算重读对象**。
旧仓库把整组选项拼成一段念出去（`共 N 个选项。选项 1：…。选项 2：…。按数字键选择。`），
`_lastSpoken` 因此是整组选项 —— 按退格重读的就是整组选项。
本作照此实现，所以选项出现后按退格能把整组再听一遍，
不用凭记忆回想有几项、分别是什么。

有配音的行也记进来 —— 语音错过了，退格把文本念出来正合适。
记忆只在内存里，退出游戏即清空。
想往回翻更多，用 `Tab` 打开回想（History）面板逐条走。留空可停用。

**`沉默键 = 0`**
按一下立刻让朗读闭嘴（相当于 TransparentHer 的「沉默按键」）。
默认 `0` —— 剧情里用不到数字键，不会和选项冲突
（选项的数字键只在选项框出现时生效）。留空可停用。

**`新台词打断上一句 = true`**
与 TransparentHer 一致（`Say(text, interrupt: true)`）。
开着时每来一句就取消正在念的那句：读得激进，但朗读不会滞后于画面。
长句没念完被打断，按「重读键」即可翻回来；嫌啰嗦就按「沉默键」。
关掉则改为排队等上一句念完 —— 一个字都不丢，但朗读会滞后于画面。
对听不见画面的盲人玩家滞后无所谓，这是给「宁可慢也不要漏」的人准备的。

**`撞上配音时清空待读队列 = true`**
只在「新台词打断上一句」关掉（=启用排队）时才有意义。
排队时若这一句要放角色语音，TTS 会和语音叠在一起、两边都听不清，
所以默认为角色语音让路。

**`朗读「正在加载」= true`**
加载时念一句「正在加载。」
读屏玩家在加载期间完全不知道游戏在干什么 —— 没画面可看、没声音可听，
很容易以为卡死了然后去乱按。
两条通路都认：Naninovel 的 `LoadingPanel`，以及名字里带 `load` 的 Unity 场景。
**会打断**正在念的那句：这条提示回答的正是"为什么没反应"，晚说几秒就完全失去意义。
被它打断的那句按「重读键」翻回来即可。

> ⚠️ 从按下按钮到游戏把加载画面显示出来，中间游戏自己还要切场景、预载资源，
> **这段时间屏幕上什么都没有**，补丁无从得知。所以听到「正在加载」总会比按键晚几秒，
> 那是游戏的静默期，不是补丁在犹豫。

**`朗读字幕 = true`**
剧本里的 `@subtitle` 字幕（片尾 / 唱歌 / 伪 ED）。

★ 这条**不是**走对话打印器的：`SubtitleUI` 播一段 Animation，文字写在预制体里的
TMP 节点上，既没有 `RevealableText` 也没有打印事件 ——
只挂打印器的话这段**一个字都不念**（玩家报告的原话就是「第四章结尾的字幕不可读」）。

开启后按画面节奏念：**滚进可见区的每一行念一次**，同一行的左/中/右几格拼成一句，
用排队而不是打断（一句接一句，打断会把上一句砍掉）。
伪 ED 是一整块往上滚，所以念的节奏和画面一致。

### `[QTE]`

**`自动点击 = true`**
剧情里有一处限时反应小游戏（QTE，在 `Prologue1_6` 剧本里）是纯视觉
反应按键：按钮散落在屏幕上、**透明 → 最实 → 渐隐消失**，得分取决于
**点击瞬间按钮的凝实程度**，低于阈值要重来。画面上没有任何可听的线索。
补丁会**等按钮出现约 1 秒再点** —— 实测 97%（刚露头就点只有 50%）。
游戏里随时按 `F3` 开关。

> **为什么是"等 1 秒"而不是"等它最实"**：按钮的渐隐不是靠 `CanvasGroup` 或
> `Image.color.a` 做的，补丁根本读不到 alpha 变化 —— 见下面「兜底延迟」那一项。

> 这个功能不可能让局面变坏：错误选项点了无事发生、没有扣分，
> 所以「把出现的按钮都点一遍」在结果上严格优于「什么都不点」。

**`开关热键 = F3`**
在游戏里切换上面那一项的按键。填 Unity 的 KeyCode 名。

**`兜底延迟（秒） = 1.0`**
★ **这就是实际生效的那个旋钮。**
实测（v0.0.0.4 日志）：按钮的渐隐不是靠 `CanvasGroup` / `Image.color.a` 做的，
补丁读不到 alpha 变化，所以「按峰值点」那条路 100 次里只触发了 1 次 ——
真正起作用的就是这个延迟。1.0 秒 = 97%。
想冲 100% 可以试 1.2~1.5，但调太大有漏点的风险。

### `[界面导航]`

**`启用键盘导航 = true`**
`Tab` 进出导航模式那一套的总开关。

**`只导航画面上可见的控件 = true`**
只把画面上真正能看到、能点到的控件纳入导航。
游戏里大量控件是「激活的」却停在画面外或被面板挡住
（隐藏的存档界面、回想里的按钮……），
关掉它们就会重新出现在导航里 —— 而且因为 Naninovel 的面板靠
`CanvasGroup` 显隐，光靠 `activeInHierarchy` 是拦不住的。
只有发现正常按钮被误排除时才需要关掉。
**注意：这一项关掉也不会退回「全收」，筛完没剩下就诚实地报「没有可操作的项目」。**

> **整屏控件都不可用时怎么办**：本作有些界面（典型的例子是彩蛋界面
> 「莉莉丝的设置界面」）游戏会把**全部**控件的 `interactable` 置成 `false`。
> 这种屏以前会报「没有可操作的项目」，读屏玩家既听不到屏幕上有什么、也不知道
> 自己为什么卡住。现在改为**只读纳入**：把这些看得见但点不动的控件也念出来
> （标签后面带「不可用」），进入时先提示一句「这一屏的控件当前都不可用，只能听，不能选」。
> 按回车只会听到「该项当前不可用。」—— **绝不会替你点下去**。
> 原则没变：无障碍层只让本来就看得见的东西变得**听得见**，
> 不让任何本来点不到的东西变得可点。

**`按屏幕位置排序 = true`**
导航顺序按控件在屏幕上的位置排（先上后下、同一行先左后右），
让「第几项」和画面对得上。
关掉则改回按渲染层级（谁后画谁在前）排序 —— 那样顺序和画面就对不上了，
除非你有特别理由，否则别关。

**`可导航文字的界面 = BacklogUI,BacklogFakeUI`**
★ 逗号分隔的路径片段。命中这些界面时，**纯文本也会变成导航项**。
用途：回想（History）面板里每条台词是一个纯文字，没有对应的控件。
纳入之后：方向键逐条翻、回车**重念当前这条** ——
「重读上一句」和「回想朗读」一次解决，而且用的是游戏本来就有的交互。
按钮/开关自带的标签会自动跳过，不会重复念。留空可停用。

**`导航时屏蔽游戏输入 = true`**
★ 建议保持开启。
回车/空格同时是「激活当前控件」和「推进剧情」。不屏蔽的话，
在回想面板里按回车重念一句，剧情会跟着往前走一格 ——
玩家只是想重听，位置却变了。
用的是引擎自己的接口 `IInputManager.ProcessInput`：
进入导航时记下当时的值再关掉，退出时还原成记下的那个值，
所以不会覆盖游戏自己因为别的原因（比如播片）关掉的输入。

**`退出前二次确认 = true`**
「退出游戏」只按一下就关掉整个会话，而读屏用户分不清它和旁边的按钮，
所以补一道确认：第一次回车只是问一句，再按一次才真的退。

**`退出按钮对象名 = ExitButton,QuitGame,ExitGameButton,QuitButton`**
哪些控件需要上面那道确认，按 Unity 对象名**精确匹配**，逗号分隔。

**`排除的面板路径 = ScriptNavigatorUI,ExternalScriptsBrowser,DebugInfoGUI,CustomVariableGUI,SaveLoadUI`**
逗号分隔的路径片段，命中就不纳入导航。默认排掉的是 Naninovel 自带的
**开发者工具**和本作**故意隐藏的存档界面**：

- `ScriptNavigatorUI` —— 「直接跳转到任意剧本」面板，里面是
  `PlayScript: Title` 这类裸剧本条目。按下去会绕开正常流程把游戏扔进裸剧本，
  实测结果是黑屏 + 有音乐 + 无任何响应，只能 Alt+F4。
  **这是实测踩过的坑，不是理论风险。**
- `SaveLoadUI` —— 本作故意不提供存/读档界面，但引擎那整套都在
  （存档/读档/快速读档三个页签 + 存档槽 + 翻页 + 删除按钮）。
  实测它曾被导航暴露成第 11、12 组（各 15 个控件）。
- 其余三个是同类调试面板。

### `[诊断]`

**`隐藏控制台窗口 = true`**
装完第一次启动时，游戏旁边会闪出一个黑色命令行窗口 —— 那是 BepInEx 的日志窗口。
补丁在**运行时**把它藏掉（`GetConsoleWindow` + `ShowWindow`），
正常情况下你看不到它。
真想看实时日志（排查问题时）就把这一项关掉。
**日志文件一直都在** `BepInEx\LogOutput.log`，藏不藏窗口都照写，诊断能力一点没少。

> 为什么不去改 `BepInEx\config\BepInEx.cfg`：那是 BepInEx 自己的配置，不该动；
> 而且你可能早就装过别的模组、那份配置未必按你想的生效。

**`详细日志 = true`**
把每一句的判定过程写进 `BepInEx\noexistence_a11y.log`：
什么时候拦下、为什么拦下、用了哪个后端、QTE 点了几个。
出问题时这个文件是唯一线索。日志不大，可以一直开着。

**`自动开始游戏 = false`** / **`自动推进剧情 = false`**
测试用。打开后引擎就绪时会自动点掉标题画面的 START，
并让剧情自己往下走。**正式游玩保持关闭。**

**`跳转脚本 = （空）`** / **`跳转热键 = （空）`** / **`跳转位置 = 0`**
★ 诊断功能，**前两项默认为空 = 关闭**。
把热键填上（例如 `F4`）、脚本填上（例如 `Prologue1_6`），
就能在游戏里按热键直接跳到那个剧本的**开头**播放（`跳转位置 = 0` 就是"开头"）。
用途：QTE 在第一章末尾，进度过了就够不着、没法回头验证功能。
跳过去之后按住 `Ctrl`（Naninovel 的跳过键）可以几秒冲到目标位置。

`跳转位置` 是**从第几行开始播**，默认 0（从开头）。
为什么默认是 0：从开头播时，脚本自己的 `@char` / `@modifyCharacter` 立绘装配命令
都会执行；从中间起播会**跳过**它们，实测角色立绘直接错乱（当初玩家原话「拼图错误」）。
只在排查某一段（例如某章结尾的字幕、某个 QTE）时临时调大，用完改回 0。

调试功能不该出现在玩家手里的默认配置里 —— 这一项真的会让游戏从别的剧本开头播起来，
而本作**没有存档/读档界面**，跳错了回不去。

> ⚠️ 会打乱正常流程，而且游戏会自动存档。用之前先备份 `Saves` 目录
> （位置见下面「关于存档」）。
> 另外：**不要试图改存档的 `playbackSpot` 跳到剧本中间** ——
> 那会跳过 `@char` / `@modifyCharacter` 的立绘分层装配命令，
> 角色立绘会直接错乱。这条也踩过。

### ⚠️ 关于存档

**这个游戏没有存档 / 读档界面**——游戏里只有 `History` 和 `Options` 两个按钮，主菜单只有「继续游戏」。这是设计如此。

但**引擎层的自动存档是存在的**，在：

```
%USERPROFILE%\AppData\LocalLow\Nino\TheNOexistenceNofyouANDme\NaninovelData\Saves\
    1.json            ← 自动存档槽（进度就存在这里）
    GlobalSave.json   ← 全局变量与解锁状态
```

「继续游戏」读的就是它。**如果你要用 `F4` 跳转做实验，先把这个目录整个备份** —— 跳过去之后游戏会把新位置写进自动存档，原来的进度就没了。

## 出问题时

**一点声音都没有。**
先确认 NVDA 已经开着，再看 `BepInEx\noexistence_a11y.log` 头两行。会写明用了哪个后端；若写着「没有可用的语音后端」，后面会跟每个后端的失败原因。

**念到某句突然没声了。**
那一句多半是**有配音的**——补丁故意让游戏语音说话，避免两路声音打架。日志里对应行是 `voiced=True`。

**为什么有人的名字念出来是「未知」？**
游戏把一个名字显示成了三个问号（`???`）。补丁**按游戏显示的原样念**，
不去猜那是谁、也不会拿别的名字替上去 —— 名字本身可能就是剧情的一部分，
替作者抖包袱不是补丁该干的事。游戏什么时候把名字显示出来，补丁就什么时候念。

**选项卡住 / 选项没念出来。**
按 `Tab` 进导航模式，用上下键找。还没有的话看日志里有没有 `CHOICE #` 行。

**黑色控制台窗口跑出来了。**
默认是藏起来的。跑出来说明「隐藏控制台窗口」被关掉了，
或者这个窗口属于**别人**的 BepInEx 模组（那就得去改对方或 BepInEx 自己的配置）。
本补丁这一项在 `BepInEx\config\noexistence.a11y.cfg` 的 `[诊断]` 里。
真想彻底关掉 BepInEx 的日志窗口：`BepInEx\config\BepInEx.cfg` →
`[Logging.Console]` → `Enabled = false`。日志文件照常写。

## 已验证到什么程度

单元级别全部在真机上跑通过。以下是从实机日志里摘的原始片段 ——
**台词原文已隐去**（那是游戏的版权内容，也是剧透；要证明的是字段判定对不对，
不是它念了什么）：

```
EVENT  author=Lilith printer=Dialogue key=Prologue2_1/~2f1a8e2c
REVEAL fresh=True printer=Dialogue author=Lilith name=莉莉丝 key=Prologue2_1/~2f1a8e2c voiced=True  text=（有配音，只放语音）
REVEAL fresh=True printer=Dialogue author=Watch  name=手表  key=Prologue2_1/~980e2215 voiced=False text=（TTS 朗读）
REVEAL fresh=True printer=Dialogue author=King   name=国王  key=Prologue2_1/~967a4075 voiced=False text=（TTS 朗读）
REVEAL fresh=True printer=Chapter_Title author=(空) name=- key=Prologue2_0/~b9164ae8 voiced=False text=（章节标题）
```

要看的四件事：`author` / `name` 一一对上了；`voiced=True` 的行只放语音、
`voiced=False` 的行走 TTS；`Chapter_Title` 这种非对话打印器也认；
`key` 是剧本名加行号，补丁靠它查配音白名单。

- 说话人解析、配音白名单、旁白不报名 —— 已跑通
- ruby 双读 —— 已在实机台词上出现（`角色扮演（实为：RPG）`、`NPC（实为：非玩家角色）`）
- 去重 —— 单次运行 `dup: 0`
- **界面导航范围** —— 玩家实机确认：主菜单按 Tab 只有 5 项，游戏内只有 History / Options；
  不会翻到隐藏面板，也不会碰到开发者工具
- **剧透闸门** —— 玩家实机确认：载入存档时不再念出不属于当前剧情的内容
- **选项朗读与数字键直选** —— 玩家实机确认：能听到选项内容，按 1 选中第 1 项
- **QTE 自动点击** —— 玩家实机确认：**修正值 97%**（刚露头就点只有 50%）。
  实测位置 `Naninovel<Runtime>/ModalUI/QTEPanel`，在 `Prologue1_6`，
  一局 65 秒、约 100 次点击

**尚未实机验证的**：终章与 ED 字幕（走的是与对话相同的打印器路径，风险低）、
加载播报的**打断**行为、`0` 沉默键、控制台窗口隐藏。
如果你玩到那里发现不对，把 `noexistence_a11y.log` 发我。

> 顺带记一个实测结论：QTE 的分数来自「点击时按钮的凝实程度」，而按钮的渐隐
> **不是**靠 `CanvasGroup` 或 `Image.color.a` 做的——补丁读不到 alpha 变化，
> 所以「按峰值点」那条路 100 次里只触发了 1 次。50% → 97% 完全来自
> 「等 1 秒再点」。要调就调配置里的「兜底延迟」。
