# 《不/存在的你和我》无障碍补丁

让盲人玩家能用屏幕阅读器完整通关本作。

适用版本：Steam 版 The NOexistenceN of you AND me（AppID 2873080），Unity 2022.3.62f2c1 / IL2CPP。

---

## 这个补丁做了什么

**读台词。** 对话、旁白、章节标题、ED 字幕全部朗读。有配音的台词只放游戏语音、不重复念；没配音的用 TTS 念，并且**先报说话人名**。

**读选项。** 本作主角**从不用文本说话**——她/他的全部台词都在选项框里，全剧 625 条以上、8000 多字。补丁会在每条选项出现时带序号念出来。

**能不用鼠标玩。** 原本选项只能用鼠标点，标题画面那个「/」要拖动。现在：

| 按键 | 作用 |
|---|---|
| `Tab` | 进入 / 退出界面导航模式 |
| `↑` `↓` | 上一个 / 下一个控件（会念出它是什么） |
| `←` `→` | 调整滑条 |
| `回车` / `空格` | 激活当前控件（导航模式外，回车和空格照常推进剧情） |
| `1` – `9` | **选项出现时直接选第 1–9 项**，不必用鼠标、也不必先进导航模式 |
| `PageUp` / `PageDown` | 切换面板组（比如设置页签） |
| `Home` / `End` | 第一项 / 最后一项 |
| **`退格`** | **重读最近朗读过的剧情文本**。连按一直往回走（最多 30 句），读到新的一句就回到最新。只在内存里，退出游戏即清空 |
| **`0`** | **沉默键**：立刻让朗读闭嘴。默认 `0`——剧情里用不到数字键，不会和选项冲突 |
| **`F3`** | 开关 QTE 自动点击（切换时会念出状态） |
| **`F4`** | 诊断用：跳到配置指定的剧本开头（默认 `Prologue1_6`），配合按住 `Ctrl` 快进 |

**自动通过 QTE。** 烤箱那段（在 `Prologue1_6`，五个按钮写着「你是烤箱」「你不是时光机器」之类）是纯视觉的反应按键：按钮散落在屏幕上、**透明→最实→渐隐消失**，修正值取决于**点击瞬间按钮的凝实程度**，低于阈值要重来。画面上没有任何可听的线索，盲人玩家不是玩得差，是根本没有可玩的通道。

补丁会等按钮渐显到最实再点——**实测 97%**（刚露头就点只有 50%）。随时按 `F3` 开关，想手动对照很方便。

> 这个功能不可能让局面变坏：错误选项点了无事发生、没有扣分，所以「把出现的按钮都点一遍」在结果上严格优于「什么都不点」。采集范围严格限制在 QTE 面板子树内，不会误碰别处的按钮。

**ruby 双读。** 本作的 `<ruby>` 旁注不是注音，而是「现实被改写」的演出层——正文是表象，旁注才是真相。补丁两个都读并标注，例如：

```
本年度最受期待的剧情向角色扮演（实为：RPG）游戏！
```

## 安装

### 前置

- **NVDA**（推荐）：补丁会自动用 NVDA Controller Client，延迟最低、不会和语音重叠。**NVDA 必须先启动**。
- 没有 NVDA 也行：会自动退到 **Tolk**（若 `Tolk.dll` 在场，可支持 JAWS / SuperNova / ZoomText），再退到 **Windows SAPI**。
- 用 SAPI 兜底时，**系统里要装有中文语音**，否则中文念不出来。检查方法：`Win + Ctrl + N` 打开「讲述人」设置，或「设置 → 时间和语言 → 语音」。

### 步骤

1. 解压 `NoExistenceA11y.zip`。
2. 右键 `install.ps1` → **使用 PowerShell 运行**。（若被策略拦住，先在一个 PowerShell 窗口里执行 `Set-ExecutionPolicy -Scope Process Bypass` 再运行。）
3. 安装器会自动找到游戏目录；找不到时手动指定：

   ```powershell
   .\install.ps1 -GameDir "D:\Steam\steamapps\common\The NOexistenceN of you AND me"
   ```

4. 装完直接启动游戏。

安装器做四件事：装 BepInEx（没有才装）→ 换掉有问题的 `Il2CppInterop.Runtime.dll` → 放插件 → 放 NVDA 客户端 DLL。**不改动任何游戏文件。**

### 卸载

删掉这些即可（都在游戏根目录）：

```
winhttp.dll
doorstop_config.ini
.doorstop_version
changelog.txt
BepInEx\
dotnet\
```

只想去掉插件、保留 BepInEx：删 `BepInEx\plugins\NoExistenceA11y.dll`。

## 配置

`BepInEx\config\noexistence.a11y.cfg`，游戏启动时读取。

| 键 | 默认 | 说明 |
|---|---|---|
| `朗读 / 启用` | 开 | 总开关 |
| `朗读 / 有配音时不再朗读` | 开 | 命中配音白名单时只放游戏语音 |
| `朗读 / 播报说话人` | 开 | 无配音台词前先报名字 |
| `朗读 / 有配音时也报名` | 开 | 莉莉丝有好几个名号（莉莉丝 / 莉莉丝公主 / 魔王莉莉丝 / 神秘少女），声音一样但换名字是重要剧情，所以有配音时也念一遍 |
| `朗读 / 朗读纯省略号` | 关 | 「……」这种只有标点的行是否也读 |
| `朗读 / 语音后端` | 自动 | 可强制 `NVDA` / `Tolk` / `SAPI`，排查用 |
| `朗读 / 重读键` | `Backspace` | 重读最近一句剧情文本；留空可停用 |
| `朗读 / 沉默键` | `0` | 立刻让朗读闭嘴；留空可停用 |
| `朗读 / 新台词打断上一句` | 开 | 与 TransparentHer 一致（`Say(text, interrupt: true)`）。关掉改成排队，一个字不丢但朗读会滞后于画面 |
| `选项框 / 朗读选项` | 开 | |
| `选项框 / 数字键直选` | 开 | |
| `QTE / 自动点击` | 开 | 配合 `F3` 随时开关 |
| `QTE / 开关热键` | `F3` | |
| `QTE / 兜底延迟（秒）` | `1.0` | **实际生效的旋钮**。1.0 秒 = 97%。按钮的渐隐补丁读不到 alpha，所以「按峰值点」那条路基本不触发，真正起作用的就是这个延迟 |
| `界面导航 / 启用键盘导航` | 开 | |
| `界面导航 / 可导航文字的界面` | `BacklogUI` | 命中这些界面的**纯文本**也变成导航项 —— 回想面板里的台词就是靠这个才读得到。方向键逐条翻，回车重念当前这条 |
| `界面导航 / 导航时屏蔽游戏输入` | 开 | 回车/空格同时是「激活控件」和「推进剧情」。不屏蔽的话，在回想里按回车重念一句，剧情会跟着往前走一格 |
| `界面导航 / 退出前二次确认` | 开 | 「退出游戏」按一下就关掉整个会话，读屏分不清它和旁边的按钮，所以补一道确认 |
| `诊断 / 详细日志` | 开 | 每句的判定过程写进 `BepInEx\noexistence_a11y.log` |
| `诊断 / 跳转脚本` | `Prologue1_6` | `F4` 跳到这个剧本的开头。**诊断功能，会打乱正常流程** |
| `诊断 / 跳转热键` | `F4` | 留空可停用 |

### ⚠️ 关于存档

**这个游戏没有存档 / 读档界面**——游戏里只有 `History` 和 `Options` 两个按钮，主菜单只有「继续游戏」。这是设计如此。

但**引擎层的自动存档是存在的**，在：

```
%USERPROFILE%\AppData\LocalLow\Nino\TheNOexistenceNofyouANDme\NaninovelData\Saves\
    1.json            ← 自动存档槽（进度就存在这里）
    GlobalSave.json   ← 全局变量与解锁状态
```

「继续游戏」读的就是它。**如果你要用 `F4` 跳转做实验，先把这个目录整个备份** —— 跳过去之后游戏会把新位置写进自动存档，原来的进度就没了。

## 出问题时

**一点声音都没有。**
先确认 NVDA 已经开着，再看 `BepInEx\noexistence_a11y.log` 头两行。会写明用了哪个后端；若写着「没有可用的语音后端」，后面会跟每个后端的失败原因。

**念到某句突然没声了。**
那一句多半是**有配音的**——补丁故意让游戏语音说话，避免两路声音打架。日志里对应行是 `voiced=True`。

**说到「未知」是谁？**
开场那段神秘人的名牌在游戏里就是三个问号（`???`）。补丁按原样念「未知」，**不念成「莉莉丝」**——那是作者埋的伏笔，念破等于剧透。

**选项卡住 / 选项没念出来。**
按 `Tab` 进导航模式，用上下键找。还没有的话看日志里有没有 `CHOICE #` 行。

**BepInEx 控制台窗口很烦。**
`BepInEx\config\BepInEx.cfg` → `[Logging.Console]` → `Enabled = false`。日志文件照常写。

## 已验证到什么程度

单元级别全部在真机上跑通过。以下是从实机日志里摘的原始片段：

```
EVENT  author=Lilith printer=Dialogue key=Prologue2_1/~2f1a8e2c
REVEAL fresh=True printer=Dialogue author=Lilith name=莉莉丝 key=Prologue2_1/~2f1a8e2c voiced=True  text=喂，快起床，要迟到了哦。
REVEAL fresh=True printer=Dialogue author=Watch  name=手表  key=Prologue2_1/~980e2215 voiced=False text=「2点40分，陛下。凌晨2点40分。」
REVEAL fresh=True printer=Dialogue author=King   name=国王  key=Prologue2_1/~967a4075 voiced=False text=公主被魔王抓走了，请将她营救回来吧，逐梦人大人。
REVEAL fresh=True printer=Chapter_Title author=(空) name=- key=Prologue2_0/~b9164ae8 voiced=False text=第二章：心跳刺激大冒险
```

- 说话人解析、配音白名单、旁白不报名 —— 已跑通
- ruby 双读 —— 已在实机台词上出现（`角色扮演（实为：RPG）`、`NPC（实为：非玩家角色）`）
- 去重 —— 单次运行 `dup: 0`
- **界面导航范围** —— 玩家实机确认：主菜单按 Tab 只有 5 项，游戏内只有 History / Options；
  不会翻到隐藏面板，也不会碰到开发者工具
- **剧透闸门** —— 玩家实机确认：载入存档时不再念出不属于当前剧情的内容
- **选项朗读与数字键直选** —— 玩家实机确认：能听到选项内容，按 1 选中第 1 项
- **QTE 自动点击** —— 玩家实机确认：**修正值 97%**（刚露头就点只有 50%）。
  实测位置 `Naninovel<Runtime>/ModalUI/QTEPanel`，在 `Prologue1_6`，
  一局 65 秒、约 100 次点击

**尚未实机验证的**：终章与 ED 字幕（走的是与对话相同的打印器路径，风险低）。
如果你玩到那里发现不对，把 `noexistence_a11y.log` 发我。

> 顺带记一个实测结论：QTE 的分数来自「点击时按钮的凝实程度」，而按钮的渐隐
> **不是**靠 `CanvasGroup` 或 `Image.color.a` 做的——补丁读不到 alpha 变化，
> 所以「按峰值点」那条路 100 次里只触发了 1 次。50% → 97% 完全来自
> 「等 1 秒再点」。要调就调配置里的「兜底延迟」。
