# 常见问题

《不/存在的你，和我》无障碍补丁的用户问题汇总。适用 **0.2.0.0**。

先看 [安装说明.md](安装说明.md) —— 键位、配置项、安装卸载都在那里；
本作和 Framework《操作逻辑公约》哪里不一样，看 [操作约定.md](操作约定.md)；
改了什么、为什么改，看仓库的 `CHANGELOG.md`。

每条按「**为什么**」写。遇到问题的第一反应应该是：

1. 看日志：`BepInEx\noexistence_a11y.log`（补丁自己的判定）和
   `BepInEx\LogOutput.log`（BepInEx 与加载期）。
2. **按 `F9`** 换一个语音后端试试（默认键，配置里可改）。
3. 还不行，按最后一条「怎么报问题」发一份日志。

---

## 点了「开始 / 继续游戏」没反应，过半天才说「正在加载」？

**这是游戏自己的静默期，不是补丁卡住了。** 点下去之后游戏要切场景、预载资源，
这期间画面是空的、声音也没有，补丁没有任何事件可听 —— 所以「正在加载」这句话
**总会比按键晚几秒**，那是游戏在干活。

旧版（0.1.x）还把这条提示排进朗读队列，要等前面几句念完才播，听起来就像卡死。
**0.2.0.0 起，加载提示一出现就打断当前朗读、立刻播报。**
被它打断的那句按 `退格` 重读即可。

加载期间**不要连点**：游戏一次只处理一个点击，连点不会让它快一点。

## 菜单里按方向键没反应 / 不知道光标停在哪？

**先确认配置 `[界面操作] 启用键盘操作 = true`**（默认就是开的）。

菜单是**自动接管**的：面板出现后，补丁每 0.35 秒探一次，候选稳定 0.2 秒
（等淡入/滑入完成）就接管 —— 也就是说**大约半秒内**键盘就可用了。
刚点开就狂按方向键可能按在接管之前，**再按一次**就好。
菜单关掉后键盘自动交还游戏，不需要按任何键退出。

如果菜单里的项**全都不可用**（游戏设的，例如彩蛋的「莉莉丝的设置界面」），
会先听到「这一屏的控件当前都不可用，只能听，不能选。」，
所有项都能听、标签带「不可用」，按回车只会听到「该项当前不可用。」。
**这是游戏把控件锁死了，不是补丁坏了**，补丁不会替你点。

> **老玩家注意：本版没有 `Tab` 导航模式了。** 不用记任何"进入/退出界面操作"的键，
> 补丁也**完全不处理** `Tab`（不再截获它，交给游戏/系统自己处理）。

还不行就看 `noexistence_a11y.log` 里 `[UiNav]` 开头的行：会写扫描到几个控件、
为什么被筛掉（不可见 / 不可用 / 被排除路径挡掉）。

## 选项点不动 / 选项没念出来？

选项出现时会**自动整组朗读**，按 `1`–`9` 直接选，不需要先按任何键。

**某一项按数字键没反应**：多半是游戏把那一项标成了不可用。
补丁只点「此刻可点、有文字、处于激活状态」的项 —— 按不动的项它在日志里会写明。
看日志 `CHOICE` 开头的行。

**整组选项都没反应**：那通常是游戏自己的状态坏了（罕见），只能重启游戏。
本作**没有存/读档界面**，进度存在自动存档里，重启后点「继续游戏」即可。
选项框整体不响应时，别指望补丁能绕过 —— 补丁是替你去点游戏自己的按钮，游戏按钮都坏了它也点不动。

选项框属于「不是菜单」的界面（配置 `非菜单界面（不自动接管）` 里），
所以**方向键在选项框上不生效**，请用数字键。
选项整组可以用 `退格` 重读。

## 完全没有声音？

按顺序查：

1. **NVDA 必须在游戏启动之前就开着。** 补丁启动时按
   `NVDA → Tolk → 争渡 → SAPI` 的顺序挑第一个能用的后端。
   补丁跑起来之后再开 NVDA 也能接上（每 10 秒重试一次），但越早开越稳。
2. **看日志头两行**：会写明选了哪个后端；一个都没有时会跟每个后端的失败原因。
3. **按 `F9`** 换后端（循环切换、跳过不可用的、写回配置文件）。
   `F9` 只是默认键，可以在配置 `切换语音后端按键` 里改。
4. **某句突然没声**：那句多半**有配音**——补丁故意让游戏语音说话（日志 `voiced=True`），
   这是设计，见下面「为什么有配音的台词只放语音」。按 `退格` 能把文本念出来。
5. 用 SAPI 兜底时要求系统装了**中文语音**，否则中文念不出来。

## 争渡（ZDSR）怎么用？为什么判「不可用」？

**要求：争渡正在运行，且是商业版 / 青春版。**
公益档没有 API 权限 —— 补丁会**如实判为不可用**，而不是假装在念。
这是争渡的授权模型，不是 bug。

判据是 `GetSpeakState()` ∈ {3（正在朗读）, 4（空闲）}，**不是** `Speak()` 的返回值：
未授权时 `Speak()` 照样返回 0，拿它当判据会「日志一片绿、耳朵一片安静」。
公益档下 `GetSpeakState()` 恒为 2。

**不需要你手动塞 dll。** 补丁先读 Windows「卸载」登记项里的 `InstallLocation`
（`DisplayName` 含「争渡」或 `zdsr` 的那些）自动找安装目录，装在别的盘也算；
搜索顺序是 **注册表登记目录 → 默认安装目录 → 插件目录（包内兜底）→ 游戏目录**，
安装目录里那份**永远优先**。

**想固定只用争渡**：配置 `语音后端 = 争渡`（写 `ZDSR` 也认）。
注意钉死之后**不会自动回退**，争渡不可用就彻底没声了。

包内 `ZDSRAPI_x64.dll` / `ZDSRAPI.dll` 是**可删的兜底**（给翻不到 dll 的人），
删掉后回到「只读争渡安装目录」，功能不变；版本不匹配时补丁会自动换下一份候选。

排查看日志这一行：`语音后端: 争渡读屏（ZDSR），DLL=…，状态=…`。

## 为什么有配音的台词只放语音、不再念文本？

**设计如此。** 本作 1502 条对话里 884 条有配音（约 86~93% 覆盖，
只有一部分角色有完整配音）。语音本身是游戏体验的一部分，
TTS 再念一遍只会把语音盖掉，两边都听不清。

想听文本：**按 `退格` 重读当前这句**（有配音的行也会被记进重读记忆）。

如果某句**明明有语音却还是用 TTS 念了一遍**，多半是「按说话人当成有配音」没匹配到。
本作的做法是按**人**过滤（默认 `莉莉丝,???`），比按行号白名单更不容易漏；
解决办法是把那个说话人的名字加进这一项（逗号分隔），而不是去改行号表。

## QTE 为什么不自动过了？

**0.2.0.0 起默认关闭自动通过**：自动辅助是"替你操作"，
会破坏这一段的沉浸感，用不用应该由玩家自己决定。

- 进入反应环节会念「反应环节。按 F3 可以自动通过。」（不打断剧情，可退格重读）。
- 想跳过这一段时**自己按 `F3`**：念「自动通过已开启。」；再按一下关闭。
  **`F3` 任何一局都有效**，不受配置「自动通过」是开是关影响。
- 不在反应环节按 `F3` 只会说明用法：「当前没有反应环节。反应环节出现时，按 F3 可以自动通过。」
- 结束时念「反应环节结束。」并带上抓到的修正值；4 秒内又出现会念「反应环节重新开始。」。
- 一直没通过的话，每 20 秒提醒一次，每局最多 3 次。

**想每局都自动通过**：把配置 `[QTE] 自动通过` 改成 `true`（以后每局默认自动）；
只是想跳过这一局，就按一次 `F3`（只影响本次运行，不写回配置）。

自动通过打开后会**等按钮出现约 1 秒再点**——实测 97%（刚露头就点只有 50%）。
它不会让局面变坏：错误选项点了无事发生、没有扣分。

> 旧版（0.1.x）默认就是自动点，而且提示文案叫「自动点击」。本版改名为「自动通过」
> 并默认关闭；旧配置里的 `自动点击` 键**不再生效**，需要删旧配置或手动改名。

## 滑条 / 音量怎么调？听到的数字是什么意思？

设置界面的三条音量（BGM / 音效 / 语音）和文字显示速度都是滑条：

- `←` / `→` 每次 5%，会念「标签，滑条，新值，共 100%，每次 5%」。
- **按住不放**约 0.45 秒后开始连续调整（每 0.12 秒一次），不用按二十次。
- 到顶/到底会念「已到顶。」；每次调整都会打断上一句，所以连按时听到的是最新值。
- 非 0–1 范围的滑条（如标题画面隐藏成就滑条，标签「标题画面滑条」）念成
  「50%（0.75 / 1.5）」这样，避免念出误导人的整数。
- **不可用的滑条**（彩蛋设置视图、载入进度条）按左右键只会听到
  「该项当前不可用。」，**不会偷偷改值**。

## 「退出游戏」按一次怎么没退？

补丁给「退出游戏」加了一道**二次确认**：第一次按回车/空格念
「这是退出游戏。再按一次回车或空格确认退出，按别的键取消。」，
再按一次才真的退（8 秒内有效）；按别的键取消。

原因：读屏用户分不清它和旁边的按钮，而按错就把整个会话关掉了。

## 菜单打开时按回车/空格，会不会顺手把剧情推进了？

不会。**补丁接管菜单期间，回车/空格只用来激活当前项**，
同一帧会拦住游戏自己的"推进剧情"处理（uGUI 的键盘提交通路也只在接管期间关闭，
退出即还原）。如果真遇到"菜单开着却推进了剧情"，请按下面「怎么报问题」发日志 ——
那说明这一屏没有被识别成菜单，属于要修的问题。

## 打字时会被补丁抢键吗？

不会。任何输入框（`TMP_InputField`）聚焦时，补丁**一个键都不碰** ——
退格就是删字，方向键就是移光标，不会被拿去重读或调滑条。
离开输入框后继续正常运行、回车进入输入框后直接打字即可。

---

## 笔记本的纸页为什么读不出来？

那几页是**手写体的图片**（字是画进图里的），游戏数据里没有对应文本 ——
补丁测过整个数据文件，特征短语 0 命中。请用**读屏软件自带的 OCR** 看这一页。

别和**假回想面板**（剧情里 `@FakeBackLog` 打开的 `BacklogFakeUI`）弄混：
那个是**文本**，补丁会朗读，打开时也能用方向键逐条翻、回车重念当前条。

---

## 这个游戏能存档/读档吗？进度存在哪？

**游戏没有存档/读档界面**（主菜单只有「继续游戏」），只有 `History` 和 `Options`。
但引擎的自动存档是有的，在：

```
%USERPROFILE%\AppData\LocalLow\Nino\TheNOexistenceNofyouANDme\NaninovelData\Saves\
    1.json            ← 自动存档槽
    GlobalSave.json   ← 全局变量与解锁状态
```

「继续游戏」读的就是它。做实验（例如用诊断跳转）前请先备份这个目录。

## 升级 / 卸载要注意什么？

**升级**：直接覆盖安装即可。但 0.2.0.0 有配置章节名和键名变化
（`[界面导航]`→`[界面操作]`；`自动点击`→`自动通过`，默认改关；
`导航时屏蔽游戏输入` 整项删除），
**建议删掉旧 `BepInEx\config\noexistence.a11y.cfg` 让游戏重新生成**，
否则旧键名不生效。

**卸载**：删掉安装说明里列的新增文件即可；只想去掉补丁就删
`BepInEx\plugins\NoExistenceA11y.dll`。卸载后别留着旧 cfg（下次再装会沿用）。

## 怎么报问题？

带上两份日志 + 一段描述，发到仓库的 Issues：

- `BepInEx\noexistence_a11y.log`（补丁判定）
- `BepInEx\LogOutput.log`（BepInEx / 加载期）
- 描述里写清：**画面在哪**、**你按了什么**、**期待发生什么**、**实际发生什么**，
  以及补丁版本（当前 0.2.0.0）。

日志里可以搜这些关键词，能快速定位是哪一环：

| 关键词 | 说明 |
|---|---|
| `EVENT` / `REVEAL fresh=True` | 台词事件与正在显示的行 |
| `REVEAL 拦下` | 被剧透闸门拦掉的行（会写原因） |
| `CHOICE 播报` / `CHOICE 数字键` | 选项朗读与数字键选择 |
| `[UiNav] 自动接管界面` / `[UiNav] 手动接管` | 界面接管了哪一屏、几项 |
| `QTE 点击` / `反应环节` | 反应环节的自动通过行为 |
| `重读` / `沉默键` | 退格重读与 `0` 沉默 |
| `SUB 念` | 字幕朗读 |
| `语音后端:` | 当前后端与路径 |

也欢迎直接说「文档哪句和实际不符」——文档和代码一样，都当 bug 修。
