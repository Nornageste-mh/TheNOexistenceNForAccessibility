# 操作约定

《不/存在的你，和我》无障碍补丁（0.2.1.0）对本作交互的登记：
哪些语义动作怎么用、与 Framework《操作逻辑公约》的差异、证据与未实测项。

- 补丁版本：**0.2.1.0**
- 对照文档：`Framework/docs/操作逻辑公约.md`、`Framework/docs/交互形态纪律.md`
- 结论一句话：**B 类补全，无模式开关。菜单一出现键盘直接可用，关掉自动交还游戏。**

---

## 1. 采用情况

### 1.1 交互形态判定

| 项 | 本作 | 说明 |
|---|---|---|
| 形态 | **B 类（补全）** | 游戏本身有键盘（Naninovel 的推进 / 跳过键），但菜单、选项没有完整的键盘焦点模型。补丁在**游戏自己的输入/焦点层**补全，不新建 UI 层、不画覆盖层。 |
| 界面键盘来源 | 补全 | 复用游戏自己的 `Selectable` / `Button.onClick` / `Toggle` / `Slider` / `TMP_InputField`；不维护第二套焦点。 |
| 激活级别 | **1 + 2** | 级别 1：直接调游戏动作（`onClick.Invoke()`、开关 `isOn`、滑条 `value`、`ActivateInputField()`）；级别 2：兜底 `ExecuteEvents.submit` 走游戏自己的事件链。不使用级别 3（扫描编号过渡）。 |
| 遗留导航模式 | **无** | 0.2.0.0 起整套删除。`UiNav.cs` 只是文件名历史沿用，不代表还有"导航模式"。 |

### 1.2 页面模型（0.2.1.0 重做）

- **一页 = 游戏自己的一个界面（UI 根）**：路径 `/ModalUI/<Name>` 或 `/UI/<Name>` 下
  **所有 Canvas 组**合并成一页，不再只操作最上面那一组
  （`UiNav.cs` 的 `SelectPage()` / `SortPage()`）。
- **页内统一按屏幕位置排序**：先上后下、同一行先左后右。
  关掉「按屏幕位置排序」才会退回按渲染层级排。
- 例：**标题画面** = 5 个按钮 + `LogoPanel` 里的「不」字滑条，同一页可达；
  **CG 画廊** = 格子 / 翻页 / 返回按钮同页可达。
- 认不出 UI 根时退回「只操作最上面那一组」，仅作兜底，不是常规路径。

### 1.3 无模式开关

- 菜单出现后：**同一页面连续两次扫描**（间隔 ≥ 0.2 秒）才接管；
  接管后 **0.8 秒静默期**内界面变化只更新状态、不重复播报
  （`IdleDetect()` / `RescanEngaged()`）。
- 菜单关闭 / 切换场景：自动退出接管，键盘交还游戏；**不按任何补丁专属键**。
- 对话 HUD（屏幕上的设置 / 回想按钮）不自动接管，用「对话界面按钮热键」
  默认 `Alt+M` 进出（`ToggleHud()` / `HudEnter()`）。
- `Esc` 不接管，交还游戏。

### 1.4 遮挡与拦截

- **遮挡保留**：只排除「画面外」与「CanvasGroup 隐藏」的控件（`FilterBlocked()`），
  看得见但被装饰 / 穿透层挡住的控件**保留可激活** —— 游戏按钮的 `onClick`
  本来就不看射线；旧版按射线筛会把画廊 / Tips 的返回按钮藏起来，玩家会困死。
- **被排除界面防点穿**：最上层是「排除的面板路径」里的界面（存档 / 读档、
  开发者面板等）时**暂不接管**（`SelectPage()`），回车不会点到背景标题画面。
- **选项框让行**：选项面板出现时 `UiNav` 完全不接管（`Update()` 里先看 `Choices.Live`），
  键盘交给数字键 `1`–`9` / `0` 沉默；不依赖路径判断，自定义选项界面也一样。

### 1.5 性能策略（0.2.1.0）

- `[诊断] 详细日志` **默认 false**：实测一次会话 10MB 日志里 84.7% 是界面扫描 dump，
  是之前卡顿的主要来源。
- 打开时也**最多每 10 秒一份清单、只在状态变化时写**（`Scan()`）。
- 空闲扫描自适应：有按键时 0.35 秒一轮；被动阅读 0.7 秒 → 1.4 秒退避（`IdleDetect()`）。
- 去掉了逐控件 UI 射线（旧版约 2.9 万次 `RaycastAll` / 场）。

## 2. 本作键位表

### 2.1 语义动作表

| 语义 | 公约默认键 | 本作实际键 | 不同原因 | 证据 |
|---|---|---|---|---|
| 浏览上一项 | `↑` | `↑` | 一致 | 安装说明；`UiNav.cs` `Update()` |
| 浏览下一项 | `↓` | `↓` | 一致 | 同上 |
| 调整减小 | `←` | `←`（只对滑条） | 一致；非滑条项不吞键 | `Adjust()` |
| 调整增大 | `→` | `→`（只对滑条） | 同上 | 同上 |
| 激活 | `Enter` / `Space` | `回车` / `空格` | 一致（接管时才接管，否则交还游戏） | `Activate()` |
| 返回 | `Esc` | `Esc`（不接管，交还游戏） | 本作 `Esc` 是游戏原生返回键，补丁不抢 | `Update()` |
| 重读当前项 | `Backspace` | `Backspace`（接管时重读当前项；未接管时重读最后一句未配音剧情） | 一致 | `Plugin.cs` `CheckRepeatHotkey()` / `UiNav.cs` `RepeatCurrent()` |
| 选项 1–9 | `1`–`9` | `1`–`9` | 一致 | `Choices.cs` |
| 沉默 / 重读台词 | `0` / `Backspace` | `0` / `Backspace` | 一致 | `Plugin.cs` |
| 切换语音后端 | `Alt+Shift+F9` | **`F9`** | `Alt+Shift` 是中文 Windows 输入法切换键，避开对玩家更省事；本作差异逐条登记在此 | `Plugin.cs` `CheckBackendHotkey()` |

### 2.2 补充键（公约语义表没有、本作新增）

| 键 | 语义 | 说明 |
|---|---|---|
| `Home` / `End` | 第一项 / 最后一项 | 长界面快速跳转，配合 ↑↓ 使用 |
| `Alt+M` | 进入 / 退出「对话界面按钮」 | 剧情对话时设置 / 回想按钮游戏只留鼠标入口；本作特有，**不是模式开关**（其他界面自动接管，不需要按） |
| `F3` | QTE 自动通过开关 | 默认关闭；任何一局都有效，切换会念状态 |

### 2.3 游戏原生占用的键（补丁不覆盖）

`回车` / `空格` 推进剧情；按住 `Ctrl` 快进；`Esc` 游戏返回；鼠标左键推进。
补丁只在界面被接管时接管方向键 / 回车 / 空格；接管期间关闭 uGUI 键盘提交、
退出时**原样还原**（`SuppressUguiNav()`）；输入框聚焦时一个键都不碰
（`InputFieldFocused()`）。

### 2.4 本作不提供的语义

**无。** 公约语义动作表逐项都已提供。未在本作发现下拉框 / 纯数值控件；
若后续遇到，按控件类型走激活 / 调整并补登记（待实测确认）。

## 3. 页面清单与控件来源

| 页面 | 路径特征（游戏对象名） | 控件来源 |
|---|---|---|
| 标题画面 | `TitleUI` / `TitleMenu` | 游戏自己的按钮；0.2.1 起 `LogoPanel` 的隐藏滑条（`Image_Title/Slider`，标签「标题插画显隐」）同页可达；RE 已核对它只改标题插画溶解外观，不参与 Konami 成就判定 |
| 设置 | `SettingsUI` / `PlayerView` | 游戏滑条（三条音量 + 文字显示速度）与按钮；彩蛋「莉莉丝的设置界面」整屏不可用 → 只读纳入 |
| 回想（History） | `BacklogUI` | 游戏按钮 + 可导航文字白名单（每条台词逐条翻、回车重念） |
| 笔记本（假回想） | `BacklogFakeUI` / `BackLogFakePanel` | 同上 |
| 确认框 | `Confirmation` | 游戏按钮（危险操作走二次确认） |
| 暂停 | `PauseUI` | 游戏按钮 |
| CG 画廊 | `NewCGGalleryUI` | 格子 / 翻页 / `ReturnButton` 同页（0.2.1 修「返回按钮被遮挡藏起来」） |
| Tips / 提示 | `TipsUI` / `TipsPanel` | 游戏按钮（返回按钮同样依赖遮挡保留） |
| 手机 | `Phone` | 游戏按钮 |
| 对话 HUD | `ControlUI` | 不自动接管；`Alt+M` 手动进出 |
| 选项框 | `ChoiceHandler` 等 | **不接管**，数字键 `1`–`9` 直选、`0` 沉默 |
| QTE | `QTEPanel` | 不接管；`F3` 才自动通过 |
| 字幕 / 加载 / 过场 / 涂抹 / 跳过 | `SubtitleUI` / `LoadingUI` / `MovieUI` / `TransitionUI` / `EraseUI` / `CustomSkipUI` 等 | 非菜单，不接管键盘 |
| 开发者工具 | `ScriptNavigatorUI` / `ExternalScriptsBrowser` / `DebugInfoGUI` / `CustomVariableGUI` | 排除（开发者面板；脚本导航实测黑屏无响应） |
| 存档 / 读档 | `SaveLoadUI` | 排除（本作故意不提供；引擎整套仍在，防止被操作暴露） |
| 未识别界面 | —— | 按菜单处理，页面名念「当前界面」 |

> 页面识别按游戏自己的 UI 根，不写"扫全部 `Selectable`"；两处美术字控件已由 RE
> （Il2CppDumper + 预制体解析）定位：标题「不」= `TitleUI/LogoPanel/Image_Title/Slider`
> （`SnappableSlider`，只控制插画溶解，标签「标题插画显隐」）；设置「你」=
> `SettingsUI/PlayerView/TitlePanel/TextPlayer` 上的普通 `Button`（`CharacterView` 对应
> 「我」/`TextCharacter`），游戏按结局状态启用/禁用——启用时本模组能导航到，禁用时鼠标
> 也点不动。详见第 4.5 节与 re-audit 报告。

## 4. 焦点、朗读与撤销

### 4.1 焦点 = 游戏自己的选中态

用 `EventSystem.SetSelectedGameObject` 让游戏按钮自己的高亮生效；
不画焦点框、不加覆盖层、不维护第二套游标。退出时清掉补丁设的选中态
（`ReleaseSelection()`）。

### 4.2 列表变化保持当前项

列表刷新时按**对象身份**（`Items.IndexOf(旧项)`）重新定位，不按旧下标
`Clamp`——0.2.1 修掉了设置面板淡入时"焦点漂移"的问题（`RescanEngaged()`）。

### 4.3 事件驱动朗读

菜单出现 / 列表变化 / 激活之后才播报；不轮询念屏、不朗读"补丁自己的状态"。
进入页面时抑制重复播报：接管后 0.8 秒静默期内只更新状态、不播报。
「界面已更新」只在**激活后列表真的变了**才说，否则重念当前项。

### 4.4 可摘除

- 关掉「启用键盘操作」→ 本模组完全不碰界面键盘，行为与没装一致。
- uGUI 的 `sendNavigationEvents` **只在接管期间关闭、退出即还原**。
- 输入框聚焦时补丁一个键都不碰（包括退格，那是删字）。
- 场景切换 / 菜单关闭自动复位，不残留选中态与拦截状态。

### 4.5 未实测项（写清楚，不当成已验证）

- 0.2.0.0 与 0.2.1.0 的新交互（自动接管、页面合并、遮挡保留、双扫接管、
  防点穿、选项让行、配音静默）**都还没有真机验证过**。
- 标题隐藏滑条与 Konami 成就已由 RE 核对：滑条只设置标题插画材质 `_DissolveValue`，
  Konami 序列由 `TitleMenu` 直接读 legacy `Input.GetKeyDown`（每键 1 秒窗口），补丁只读
  按键、不合成输入，**推断不影响成就**；仍需按 T5 在真机确认一次。
- 设置界面「你」/「我」字按钮：已定位为普通 `Button`，是否出现取决于游戏按结局状态的
  启用逻辑；RE 报告留有「具体拦截闸门需用户开 diag 复现」的待确认项。
- 游戏内按默认 `F9` 切换后端只有平台层 / 解析层证据，没在游戏里真按过。
