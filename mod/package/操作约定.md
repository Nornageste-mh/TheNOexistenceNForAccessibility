# 操作约定

本文件登记《不/存在的你，和我》无障碍补丁的**键位与交互约定**，
以及与 Framework《操作逻辑公约》《交互形态纪律》的差异。

- 补丁版本：**0.2.0.0**
- 对应代码：`mod/src/NoExistenceA11y/Plugin.cs`、`UiNav.cs`、`Qte.cs`、`Choices.cs`
- 玩家向的键位与配置说明见 `安装说明.md`；问题排查见 `常见问题.md`；
  改动历史见仓库根目录 `CHANGELOG.md`。

---

## 1. 采用情况

### 1.1 交互形态判定：**B 类**（游戏有键盘，但不完全）

- 游戏本身**有键盘输入**：`回车` / `空格` 推进剧情、按住 `Ctrl` 快进、
  `Esc` 返回 / 关闭菜单、鼠标左键推进。
- 但**菜单与选项没有完整的键盘操作**：标题画面、设置、回想、选项框都依赖鼠标点击。
- 按《交互形态纪律》，本作属于 **B 类**：在**游戏自己的输入 / 焦点层补全**键盘操作，
  **不新建 UI 层、不引入模式开关**；补丁只让"本来就看得见、本来就能点"的控件
  可键盘操作，不扩大可达范围。

### 1.2 界面键盘来源：**补全**（不是制造，也不是原生）

- 界面项全部来自游戏自己的 `Selectable`（`UiNav` 逐帧扫描）
  与白名单界面里的 `TMP_Text`（回想 / 笔记本），**不自己造控件、不自绘覆盖层**。
- 焦点用游戏自己的选中态（`EventSystem.SetSelectedGameObject` 让游戏按钮的高亮生效），
  补丁不画焦点框，也不维护"第二套游标"（只维护"当前第几项"用于播报）。

### 1.3 激活级别：**级别 1 + 级别 2**（不使用级别 3）

| 控件 | 本作做法 | 级别 |
|---|---|---|
| `Button` | 直接调用**游戏按钮自己的** `onClick.Invoke()`（游戏自己的点击回调） | 1 |
| `Toggle` | 直接改游戏 `Toggle.isOn`（游戏自身状态与回调） | 1 |
| `Slider` | 直接写游戏 `Slider.value`（触发游戏自己的 `onValueChanged`，音量/速度由游戏应用） | 1 |
| `TMP_InputField` | 调用游戏输入框自己的 `ActivateInputField()`，进入后**完全不抢键** | 1 |
| 其它可提交控件 | `ExecuteEvents.submit`（走 Unity UI 事件链） | 2 |

- **不使用级别 3**：不按屏幕坐标合成点击、不 SendInput / PostMessage、不维护编号点击表。
- 一次激活只派发一次：激活后同一帧拦截"游戏自己按回车推进剧情"的处理，
  并记录 `_submitHandledFrame`，不会点两下。
- 证据：`mod/src/NoExistenceA11y/UiNav.cs:2004`（Activate）、
  `UiNav.cs:2121`（Adjust）、`UiNav.cs:2157`（Update 尾部）。

### 1.4 遗留导航模式：**无**（0.2.0.0 已删除）

- 0.1.x 曾提供「按 `Tab` 进入 / 退出界面导航模式」的补丁专属状态（《交互形态纪律》反模式 X1）。
- **0.2.0.0 起整套删除**：不再处理 `Tab`、`PageUp` / `PageDown`，改为"菜单出现自动接管、
  菜单关闭自动交还"。代码中 `UiNav.Update` 已无 `Tab` 分支（`UiNav.cs:2157`），
  变更记录见 `CHANGELOG.md` 的 0.2.0.0 条目。
- 文件名 / 类名 `UiNav` 是历史沿用（"界面导航"），不代表还有导航模式；
  行为以本文件与 `安装说明.md` 为准。

## 2. 本作键位表

### 2.1 语义动作

| 语义 | 《操作逻辑公约》默认键 | 本作实际键 | 不同原因 | 证据 |
|---|---|---|---|---|
| 浏览上一项 | `↑` | `↑` | 与公约一致 | `UiNav.cs:2157`（Update 尾部方向键分支） |
| 浏览下一项 | `↓` | `↓` | 与公约一致 | 同上 |
| 调整减小 | `←` | `←` | 与公约一致，但**只对滑条生效**；非滑条项不吞键 | `UiNav.cs:2121`（Adjust） |
| 调整增大 | `→` | `→` | 同上 | 同上 |
| 激活当前项 | `Enter` / `Space` | `回车` / `空格` | 与公约一致；菜单未接管时照常推进剧情 | `UiNav.cs:2004`（Activate） |
| 返回 | `Esc` | **不接管，交还游戏** | 本作 `Esc` 是游戏原生返回键（公约总则第 2 条：不覆盖游戏原生键）；补丁检测到页面消失后自动退出界面操作 | `UiNav.cs:2157`（无 Esc 分支，靠 `PageStillAlive` 退出） |
| 重读当前项 | `Backspace` | `退格` | 与公约一致；未接管界面时退化为"重读最近一段朗读" | `Plugin.cs:188`、`Plugin.cs:569`、`UiNav.cs:294` |
| 选项直选 | `1`–`9` | `1`–`9` | 与公约一致；不必先按任何键 | `Plugin.cs:273`、`Choices.cs:231-243` |
| 沉默 | `0` | `0` | 与公约一致 | `Plugin.cs:203`、`Plugin.cs:595` |
| 重读台词 | `Backspace` | `退格` | 本作**不回溯**，只记最近一次；选项整组算"一段" | `Plugin.cs:556-590`、`Choices.cs:209-216` |
| 切换语音后端 | `Alt+Shift+F9` | **`F9`** | 逐作必绑；本作 `F9` 不与游戏、Steam、读屏器、输入法冲突（`Alt+Shift` 恰是输入法切换键，避开更好）；可改任意「修饰键+主键」 | `Plugin.cs:182`、`Hotkey.cs` |

### 2.2 补充键（公约语义表之外，属本作特有）

| 键 | 作用 | 为什么需要 | 证据 |
|---|---|---|---|
| `Home` / `End` | 第一项 / 最后一项 | 设置项与回想可能较长，逐项走效率低；不与游戏原生键冲突 | `UiNav.cs:2157` |
| `Alt+M` | 进入 / 退出「对话界面按钮」 | 本作剧情对话时，屏幕上的「设置」「回想」按钮**游戏只留了鼠标入口**，且这类 HUD 不能自动接管（否则会抢剧情推进键） | `Plugin.cs:320`、`Plugin.cs:815`、`UiNav.cs:223-238` |
| `F3` | 切换 QTE「自动通过」 | QTE 是纯视觉限时反应，无任何可听线索；自动通过是玩家**可选**的辅助，不是默认代打 | `Qte.cs:147-190`、`Plugin.cs:288` |

> 补充键只增加"额外的入口"，不改变公约语义；`Alt+M` 与 `F3` 均为**本作特有语义**，
> 已在安装说明逐条向玩家说明。

### 2.3 游戏原生占用的键（补丁不抢）

| 键 | 游戏内作用 | 补丁行为 |
|---|---|---|
| `回车` / `空格` | 推进剧情 / 确认 | 菜单未接管时完全不碰；接管时只用于激活当前项，并同一帧拦住游戏推进 |
| `Ctrl`（按住） | Naninovel 快进 | 不占用 |
| `Esc` | 返回 / 关闭菜单 | 不接管，交还游戏 |
| 鼠标左键 | 推进 / 点击 | 完全不碰（不合成鼠标事件） |

### 2.4 本作不提供的语义

- **无**（公约语义表各项在本作都有对应：交还游戏的项如"返回"由游戏原生提供）。
- 待确认：本作界面里**未发现下拉框 / 数值输入控件**，因此 `←` `→` 的
  "下拉 / 数值"分支没有实际对象；如后续发现该类控件，按 `UiNav.Adjust` 的现有语义补齐。
- 界面操作**不提供**"按编号选第 N 项"（反模式 X7）：导航项按屏幕位置顺序，
  玩家只需 `↑` `↓`，不需要背编号。

## 4. 焦点、朗读与撤销

### 4.1 焦点

- 焦点 = **游戏自己的选中态**：进入界面操作后通过
  `EventSystem.SetSelectedGameObject` 让游戏的按钮高亮生效；
  退出 / 切换页面时 `ReleaseSelection` 清掉补丁设的选中项（`UiNav.cs:569` 附近）。
- 补丁**不画**焦点框、不叠加高亮、不改变控件外观与位置（《交互形态纪律》"不添物"）。
- 页面顺序默认按屏幕位置（`按屏幕位置排序=true`），排序用屏幕像素坐标，
  避免世界坐标分档导致"按下光标却跳到上方"。

### 4.2 朗读

- 剧情/选项：由**游戏事件驱动** —— `RevealableText.set_Text` + `OnPrintTextStarted`，
  不是定时扫屏；剧透闸门只念"同时收到打印事件且面板可见"的行（`Plugin.cs:124`）。
- 界面项：游戏本身不提供读屏文本，由补丁在**游戏控件状态变化时**朗读
  （页面进入 / 焦点移动 / 值改变 / 激活），播报内容 = 游戏自己的标签 + 控件类型 + 当前值。
- 进入页面先报「界面名，共 N 项。」，再报当前项；
  同页 3 秒内退出又进入时不重复报页面名；激活按钮若没换页，补播「已激活「标签」。」。
- 加载 / QTE / 字幕等环境播报用排队或打断策略，均可用 `退格` 重读。

### 4.3 撤销 / 可摘除

- **关掉补丁（或删 DLL）后**：键位、界面行为、画面与没装时完全一致 ——
  没有常驻钩子、没有覆盖层、不改游戏文件与游戏配置。
- 旧的"每帧无条件关 `sendNavigationEvents`"已改为**只在界面接管期间关闭**，
  退出时把原值写回（`UiNav.cs:313`）。
- 「启用键盘操作」关掉后，本模组完全不碰界面键盘（`Plugin.cs:303`）。
- 输入框聚焦时（`TMP_InputField.isFocused`）补丁**一个键都不碰**，
  保证打字不被抢（`UiNav.cs:340`）。
- 场景切换 / 页面消失时自动退出界面操作并复位状态（`UiNav.cs:2157`）。
